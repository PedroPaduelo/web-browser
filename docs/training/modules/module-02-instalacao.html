Módulo 2: Instalação e Configuração Inicial

Aprenda a instalar o Serende em um servidor Ubuntu/Debian e configurar o ambiente de produção.

Duração estimada45 minutos
DificuldadeIntermediário
RequisitosAcesso a servidor Ubuntu/Debian com root ou sudo

�� Instalação Passo a Passo

1. Atualizar o sistema 
sudo apt update && sudo apt upgrade -y
2. Instalar dependências do sistema 
sudo apt install -y \\
  nodejs npm python3 python3-pip ffmpeg xvfb \\
  chromium-browser libnss3 libgconf-2-4 libxss1 \\
  libappindicator3-1 libasound2 libatk-bridge2.0-0 \\
  libgtk-3-0 libgbm1 build-essential curl git
3. Verificar versões instaladas 
node --version   # deve ser v18.x
npm --version    # deve ser 9.x+
python3 --version
ffmpeg -version
Xvfb -version
4. Clonar o repositório 
cd /opt
sudo git clone https://github.com/PedroPaduelo/serende.git
cd serende
sudo chown -R $(whoami):$(whoami) .
5. Instalar dependências Node.js 
npm ci --only=production

O npm ci garante instalação limpa baseada no lockfile. Use --only=production para evitar devDependencies no container.

6. Criar arquivo .env 
cp .env.example .env
nano .env

Consulte a seção "Variáveis de Ambiente" abaixo para preencher corretamente.

7. Criar diretório de dados 
mkdir -p data/profiles
chmod 755 data/profiles
8. Build para produção 
npm run build

O comando usa tsup para bundling e gera arquivos em dist/.

9. Testar inicialização 
node dist/index.js

Verifique se o servidor inicia sem erros. Pressione Ctrl+C para parar.

10. Configurar PM2 (process manager) 
npm install -g pm2
pm2 startup
pm2 save

O PM2 mantém o processo rodando após logout e reinicia automaticamente em crashes.

11. Iniciar com PM2 
pm2 start npm --name serende -- run start
pm2 logs serende   # verifique os logs iniciais
pm2 save
12. Testar API health 
curl http://localhost:3333/health

Retorno esperado: {"status":"ok","timestamp":"..."}

💡 Dica: Para ambientes Docker, consulte container/Dockerfile e docker-compose.yml no repositório.

🧪 Testes de Sanity (Validação Pós-Instalação)

Execute estes testes para confirmar que o sistema está operacional.

1. Health Check

curl http://localhost:3333/health

Esperado: {"status":"ok"}

2. Criar uma chave API (via SQLite ou script)

node dist/scripts/create-key.js --tenant demo

Resposta: chave em formato sk_...

3. Login (obter JWT)

curl -X POST http://localhost:3333/api/auth/login \\
  -H "Content-Type: application/json" \\
  -d '{"apiKey":"sk_demo_..."}'

Esperado: {"token":"eyJ...","tenantId":"demo"}

4. Criar sessão

TOKEN=$(curl -s -X POST http://localhost:3333/api/auth/login \\
  -H "Content-Type: application/json" \\
  -d '{"apiKey":"sk_demo_..."}' | jq -r .token)

curl -X POST http://localhost:3333/api/sessions \\
  -H "Authorization: Bearer $TOKEN" \\
  -H "Content-Type: application/json" \\
  -d '{"url":"https://example.com"}'

Esperado: {"sessionId":"abc123","wsUrl":"ws://...","streamUrl":"..."}

5. Verificar processos

ps aux | grep -E "(Xvfb|chrome|ffmpeg)"

Você deve ver processos Xvfb, chrome e ffmpeg rodando.

6. Testar streaming

curl -H "Authorization: Bearer $TOKEN" \\
  "http://localhost:3333/api/sessions/abc123/stream" \\
  --output /tmp/test.mjpeg

O arquivo /tmp/test.mjpeg deve conter dados binários MJPEG.

🛠️ Troubleshooting Comum

❌ "Cannot find module 'chrome-launcher' (ou similar)"

Causa: Dependências não instaladas.

Solução: npm ci novamente.

❌ Chrome não inicia: "No space left on device"

Causa: /dev/shm muito pequeno (Chrome usa memória compartilhada).

Solução: Editar server/session-manager.js para adicionar --disable-dev-shm-usage.

❌ "Error: spawn ffmpeg ENOENT"

Causa: FFmpeg não instalado ou não no PATH.

Solução: which ffmpeg. Se não encontrado, instalar via apt.

❌ Porta 3333 já em uso

Solução: Mudar PORT no .env ou liberar a porta.

❌ Xvfb falha: "Fatal server error"

Causa: Display já em uso ou permissões.

Solução: Verifique se não há processos órfãos: pkill Xvfb.

❌ Streaming vazio (imagem não aparece)

Diagnóstico: FFmpeg está rodando? Verifique com ps aux | grep ffmpeg.

Solução: Teste manual: ffmpeg -f x11grab -video_size 1280x720 -i :99.0 -vframes 1 out.jpg
