Módulo 6: Controle de Input (Mouse e Teclado)

Aprenda como o sistema processa eventos de input, como enviar comandos via API e garantir consistência no cliente.

Duração estimada30 minutos
DificuldadeIntermediário
Pré-requisitosMódulo 5

🎯 Objetivos deste módulo

  • Entender o fluxo de input no backend

    JSON → Node → Python X11 → Xvfb → Chrome.

  • Enviar eventos de mouse e teclado via API

    Formatos suportados e exemplos.

  • Mapear teclas e garantir segurança

    Validação de códigos, injeção e limites de taxa.

🔧 Arquitetura do Input

O input é tratado por três camadas:

  1. HTTP/WS API no Node.js: recebe JSON do cliente.
  2. Input Handler em Node.js (+ Python): valida e envia para Python via stdin pipe.
  3. Python X11 (x11-input.py): converte para eventos XTest e envia para o display associado.
Observação: Todas as ações de input são logadas e metrificadas (Activity Tracker) para prevenir abuso.

Tipos de eventos aceitos

TipoCamposDescrição
mousemovex, yMove o cursor em coordenadas absolutas.
mousedownx, y, buttonPressiona o botão do mouse.
mouseupx, y, buttonSolta o botão do mouse.
keydownkeyPressiona tecla no teclado.
keyupkeySolta tecla.
wheeldeltaX, deltaYScroll de roda.
scrollx, yScroll por coordenada (se suportado).

📡 Endpoint de Input

POST /api/sessions/:sessionId/input
Authorization: Bearer <token>
Content-Type: application/json

{
  "events": [
    { "type": "mousemove", "x": 640, "y": 360 },
    { "type": "mousedown", "x": 640, "y": 360, "button": 1 },
    { "type": "mouseup", "x": 640, "y": 360, "button": 1 },
    { "type": "keydown", "key": "a" },
    { "type": "keyup", "key": "a" }
  ]
}
Requisito: Sessão ativa, token válido e sessão autenticada para o tenant correto.

Resposta padrão

{
  "success": true,
  "processed": 5,
  "failed": 0
}

🐍 Detalhes do x11-input.py

O script Python recebe JSON no stdin, parseia e dispara eventos X11 via XTest.

Exemplo de evento JSON

{
  "type": "mousemove",
  "x": 400,
  "y": 300
}

Mapeamento de teclas

Usa tabela de keysyms. Exemplo supportado:

  • Enter → XK_Return
  • Backspace → XK_BackSpace
  • Escape → XK_Escape
  • Ctrl, Shift, Alt
  • a-z, 0-9, símbolos

⚠️ Segurança e Limites

  • Validação obrigatória de input: O servidor valida o tipo, campos obrigatórios e ranges (x/y dentro da resolução).
  • Rate Limit: 100 microssegundos entre eventos (configurável). Excesso gera 429.
  • Anti-abuso: O Activity Tracker pode encerrar sessões com padrões suspeitos (cliques contínuos, flood).
  • Sem execução de shell: Não existem comandos de shell enviados via input — apenas eventos X11.
