Cheat Sheet — Serende

Referência rápida de comandos, endpoints e variáveis essenciais para administradores e desenvolvedores.

Autenticação

POST /api/auth/login
Body: { "apiKey": "sk_demo..." }
↓
{ token, tenantId }

Header: Authorization: Bearer <token>

VarDefault
JWT_SECRETobrigatório
JWT_EXPIRY24h

Sessões

POST /api/sessions
{ url, width?, height?, fps?, quality? }
↓
{ sessionId, cdpPort, display, streamUrl }

GET /api/sessions/:id
DELETE /api/sessions/:id
POST /api/sessions/:id/navigate

Timeout: SESSION_TIMEOUT_MS (default 6min)

Streaming (MJPEG)

GET /api/sessions/:id/stream
→ multipart/x-mixed-replace

<img src="/api/sessions/...">
ParâmPadrão
width1280
height720
fps15
quality5

Input (Mouse/Teclado)

POST /api/sessions/:id/input
{ "events": [
  { "type":"mousemove", "x":100,"y":200 },
  { "type":"mousedown", "button":1 },
  { "type":"keydown", "key":"a" }
]}

Types: mousemove, mousedown, mouseup, keydown, keyup, wheel, scroll

CDP (Chrome DevTools)

POST /api/cdp/:port/:method
{ "params": {...} }

Ex:
POST /api/cdp/9223/Page.navigate
{ "url": "https://..." }

POST /api/cdp/9223/Page.captureScreenshot

Porta obtida na resposta de POST /api/sessions.

Admin API

# Criar chave
POST /api/admin/keys
{ tenantId, label? }

# Listar chaves
GET /api/admin/keys

# Revogar
DELETE /api/admin/keys/:id

# Sessões ativas
GET /api/admin/sessions

# Stats
GET /api/admin/stats

Header: x-admin-secret: <segredo>

FFmpeg Quality/FPS

  • Leve: 800×600 @ 10fps, q=7 (~0.5 Mbps)
  • Balanço: 1280×720 @ 15fps, q=5 (~2 Mbps)
  • Alta: 1920×1080 @ 20fps, q=3 (~5 Mbps)

MJPEG não é para vídeos longos.

Troubleshooting Rápido

  • Chrome não inicia: faltam libs? apt install libnss3 libgconf-2-4
  • FFmpeg ENOENT: instalar ffmpeg e verificar PATH.
  • Stream vazio: processo ffmpeg morto, verifique logs.
  • Porta ocupada: mudar PORT no .env.
  • Token expirado: refaça login.
