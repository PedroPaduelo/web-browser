🔐 Autenticação

A Serende usa duas formas de autenticação:

API Key (para login)

POST /api/auth/login

Use sua API key para obter um token JWT:

curl -X POST https://serende.ddw1sl.easypanel.host/api/auth/login \\
  -H "Content-Type: application/json" \\
  -d '{"apiKey":"serende-dev-key-2024"}'

Resposta:

{
  "token": "eyJhbG...",
  "tenantId": "cb9bebdc303f4541",
  "userId": "cb9bebdc303f4541"
}

Bearer Token (para APIs protegidas)

Para todas as demais requisições, use:

Authorization: Bearer <token>

🌐 API REST

Criar Sessão

POST /api/session

Cria uma nova sessão de navegador remoto.

curl -X POST https://serende.ddw1sl.easypanel.host/api/session \\
  -H "Authorization: Bearer <token>" \\
  -H "Content-Type: application/json" \\
  -d '{"startUrl":"https://google.com","resolution":"1280x720"}'

Parâmetros opcionais:

  • startUrl: URL inicial (padrão: https://google.com)
  • resolution: Resolução "WxH" (padrão: 1280x720)

Resposta:

{
  "sessionId": "2a13ba28-7e0d-481a-a2a9-04013e8a9843",
  "status": "running",
  "resolution": {"width": 1280, "height": 720}
}

Listar Sessões

GET /api/session 
curl -H "Authorization: Bearer <token>" \\
  https://serende.ddw1sl.easypanel.host/api/session

Obter Sessão

GET /api/session/:sessionId

Retorna detalhes da sessão incluindo cdpPort, display e timeout.

Navegar

POST /api/navigate/:sessionId 
curl -X POST https://serende.ddw1sl.easypanel.host/api/navigate/<sessionId> \\
  -H "Authorization: Bearer <token>" \\
  -H "Content-Type: application/json" \\
  -d '{"url":"https://exemplo.com"}'

Screenshot

GET /api/screenshot/:sessionId

Retorna imagem JPEG. Use diretamente em <img src="...">.

Input (Mouse/Teclado)

POST /api/input

Envia eventos de input para a sessão:

{
  "sessionId": "...",
  "type": "mouse_move" | "mouse_click" | "key_press" | "scroll",
  "x": 100, "y": 200,
  "button": 0,
  "key": "Enter"
}
POST /api/input/batch

Envia múltiplas ações de uma vez (mais eficiente).

Stopping a Session

DELETE /api/session/:sessionId

🤖 MCP Server (Model Context Protocol)

O MCP Server fornece 45+ ferramentas para AI agents controlarem o navegador via JSON-RPC 2.0 sobre Streamable HTTP.

Endpoint MCP

POST /mcp

Use o header X-API-Key: serende-dev-key-2024 (ou uma API key do admin).

Handshake

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-03-26",
    "capabilities": {},
    "clientInfo": {"name": "test", "version": "1.0"}
  }
}

Resposta:

{
  "result": {
    "protocolVersion": "2025-03-26",
    "capabilities": {"tools": {"listChanged": true}},
    "serverInfo": {"name": "serende-browser", "version": "3.0.0"}
  },
  "jsonrpc": "2.0",
  "id": 1
}

Chamando Ferramentas

Todas as ferramentas são chamadas via tools/call:

{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "session_start",
    "arguments": {"startUrl": "https://google.com"}
  }
}
✅ MCP Server Validado: Testado e funcionando na porta 4202 com 45 ferramentas ativas.

💡 Exemplos Práticos

Fluxo Completo via API REST

# 1. Login
TOKEN=$(curl -s -X POST https://serende.ddw1sl.easypanel.host/api/auth/login \\
  -H "Content-Type: application/json" \\
  -d '{"apiKey":"serende-dev-key-2024"}' | jq -r .token)

# 2. Criar sessão
SESSION=$(curl -s -X POST https://serende.ddw1sl.easypanel.host/api/session \\
  -H "Authorization: Bearer $TOKEN" \\
  -H "Content-Type: application/json" \\
  -d '{"startUrl":"https://google.com"}' | jq -r .sessionId)

# 3. Navegar
curl -X POST https://serende.ddw1sl.easypanel.host/api/navigate/$SESSION \\
  -H "Authorization: Bearer $TOKEN" \\
  -H "Content-Type: application/json" \\
  -d '{"url":"https://github.com"}'

# 4. Screenshot (salvar em arquivo)
curl -H "Authorization: Bearer $TOKEN" \\
  https://serende.ddw1sl.easypanel.host/api/screenshot/$SESSION \\
  -o screenshot.jpg

# 5. Parar sessão
curl -X DELETE https://serende.ddw1sl.easypanel.host/api/session/$SESSION \\
  -H "Authorization: Bearer $TOKEN"

Fluxo Completo via MCP

# Inicializar
curl -s -X POST https://serende.ddw1sl.easypanel.host:4202/mcp \\
  -H "X-API-Key: serende-dev-key-2024" \\
  -H "Content-Type: application/json" \\
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"agent","version":"1.0"}}}'

# Iniciar sessão
curl -s -X POST https://serende.ddw1sl.easypanel.host:4202/mcp \\
  -H "X-API-Key: serende-dev-key-2024" \\
  -H "Content-Type: application/json" \\
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"session_start","arguments":{"startUrl":"https://google.com"}}}'

# Navegar
curl -s -X POST https://serende.ddw1sl.easypanel.host:4202/mcp \\
  -H "X-API-Key: serende-dev-key-2024" \\
  -H "Content-Type: application/json" \\
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"navigate","arguments":{"url":"https://github.com"}}}'

# Screenshot
curl -s -X POST https://serende.ddw1sl.easypanel.host:4202/mcp \\
  -H "X-API-Key: serende-dev-key-2024" \\
  -H "Content-Type: application/json" \\
  -d '{"jsonrpc":"2.0","id":4,"method":"tools/call","params":{"name":"screenshot","arguments":{}}}'

🛠️ Ferramentas MCP Disponíveis

O MCP Server expõe 45+ ferramentas (consulte a lista completa via tools/list). Principais categorias:

Gerenciamento de Sessão

  • session_start — inicia nova sessão
  • session_stop — encerra sessão
  • session_status — detalhes da sessão atual
  • list_sessions — lista sessões ativas

Navegação

  • navigate — navega para URL (aguarda carregamento)
  • get_url — obtém URL atual
  • wait_for_page_ready — aguarda página interativa
  • wait_for_url — aguarda mudança de URL
  • wait_for_element — aguarda elemento aparecer

Interação

  • mouse_move, mouse_click, mouse_double_click
  • drag — arrastar com interpolação suave
  • scroll — rolagem
  • key_press, key_down, key_up, type_text
  • hotkey — atalhos (ex: Ctrl+A)

Formulários e Elementos

  • find_element, find_all_elements, find_element_by_text
  • click_element, click_by_text — clique robusto
  • react_fill_input — preenchimento React-compatível
  • fill_form — múltiplos campos
  • submit_form — submissão automática

Dados e DOM

  • get_page_title, get_page_text, get_page_html
  • get_elements — dados detalhados de elementos
  • evaluate_js — executa JavaScript
  • get_cookies, set_cookie, delete_cookie
  • get_console_messages — logs do browser
  • get_network_activity — requests/reponses

Screenshot

  • screenshot — captura tela atual
  • screenshot_after — captura após delay (útil para animações)

Utilitários

  • wait_for_text, wait_for_selector_gone
  • clipboard_write, clipboard_read
  • health — verifica conexão
