Arquitetura do Sistema

O Serende é composto por backend Node.js, frontend React e instâncias Chrome headless. Cada componente tem responsabilidades bem definidas e se comunicam via HTTP/WebSocket.

Visão Geral da Arquitetura

Componentes do Sistema

🌐

Frontend React

Interface SPA com Canvas para renderização MJPEG. Gerencia conexão WebSocket, controles de sessão e input relay.

React 18 Vite Canvas API
🔧

Backend API

Servidor Express com autenticação JWT, rate limiting, CORS e APIs REST para sessões, navegação e profile.

Express JWT ws
💻

Session Manager

Gerencia ciclo de vida das sessões Chrome: start, stop, health check, timeout tracker e allocation de displays.

Xvfb Chrome CDP
📺

Stream Manager

Recebe frames JPEG do CDP e faz broadcast via WebSocket para todos os clientes conectados com backpressure handling.

WebSocket MJPEG Broadcast
🖱️

Input Handler

Converte eventos de mouse/teclado do frontend em eventos X11 (XTest) que são injetados no Chrome via display virtual.

X11 XTest Python
🔑

Auth & Tenant

Autenticação via API Key → JWT. Isolamento de tenants com limites de sessão e profile separado por tenantId.

JWT SQLite KeyStore
