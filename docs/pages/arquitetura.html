Arquitetura do Sistema

Visao Geral

Serende e um sistema de navegador remoto via web. Permite que usuarios acessem um Chrome headless rodando em um servidor, com streaming de video em tempo real e controle remoto de mouse/teclado. Similar a VNC mas usando Chrome como display server.

A arquitetura e multi-tenant com isolamento por API keys, garantindo que cada tenant tenha suas sessoes, profiles e dados completamente separados.

Componentes Principais

Xvfb (X Virtual Framebuffer)

Display virtual X11, utilizando displays :100 a :199. Nao requer hardware de video real, criando um framebuffer em memoria para que o Chrome renderize.

Chrome Headless

Navegador Chrome rodando em modo headless com CDP (Chrome DevTools Protocol) na porta 9222+. Renderiza paginas web no display virtual Xvfb.

FFmpeg

Captura o display via x11grab e codifica em MJPEG. Roda a 30 FPS com qualidade Huffman 5 (q:v 5), enviando frames via stdout (pipe:1).

Python X11 Input

Utiliza python-xlib e XTest extension para injetar eventos de mouse e teclado no display virtual X11. Um processo por sessao.

Stream Manager

Faz parse de frames JPEG individuais do stdout do FFmpeg (marcadores SOI 0xFFD8 e EOI 0xFFD9), e faz broadcast binario para todos os clientes WebSocket conectados.

Profile Manager

Gerencia o Chrome userDataDir por tenant. Na criacao da sessao copia o profile master, no encerramento faz merge de volta. Persistencia de cookies, historico e extensoes.
