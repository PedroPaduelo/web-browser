🏗️ Arquitetura do Sistema

Visão Geral

O Serende é um sistema de navegador remoto via web, similar a VNC mas utilizando Chrome headless como display server. A arquitetura segue o padrão multi-tenant com isolamento por API keys.

Componentes Principais

🖥️ Xvfb (X Virtual Framebuffer)

Servidor X virtual sem necessidade de hardware de vídeo. Permite executar aplicações gráficas em ambiente headless.

  • Porta padrão: :99
  • Função: Display virtual
  • 🔄 Fluxo Completo

🌐 Chrome Headless

Navegador Chrome executando em modo headless com CDP (Chrome DevTools Protocol) habilitado.

  • Função: Renderização de páginas
  • Debug port: 9222
  • 🔄 Fluxo Completo

🎬 FFmpeg

Captura a tela do Xvfb via x11grab e codifica em MJPEG para streaming.

  • Entrada: x11grab
  • Saída: MJPEG stream
  • 🔄 Fluxo Completo

🐍 Python X11 Input

Daemon Python que usa XTest para injetar eventos de mouse e teclado no Xvfb.

  • Biblioteca: python-xlib
  • Entrada: Mensagens JSON via stdin
  • 🔄 Fluxo Completo

Fluxo de Dados Principal

1 Requisição HTTP Usuário inicia sessão via REST API
→
2 Session Manager Spawn de Xvfb + Chrome + FFmpeg
→
3 WebSocket Streaming de vídeo + Input relay
→
4 Browser Viewer Renderização no Canvas + Audio
