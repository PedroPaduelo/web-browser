Input Relay (Mouse/Teclado)

Sistema que captura eventos do frontend e os injeta no Chrome via X11 (XTest). Permite controle remoto completo do navegador.

Fluxo de Input

Tipos de Eventos Suportados

Tipo Parâmetros X11 Equivalent
mouseMove {x, y} MotionNotify
mouseDown {x, y, button} ButtonPress
mouseUp {x, y, button} ButtonRelease
keyDown {key} KeyPress
keyUp {key} KeyRelease
scroll {x, y, deltaY} ButtonPress + Motion

Código: Input Handler

cdp-input-handler.js (Node)

function createInputHandler(displayNum) {
  return {
    display: `:${displayNum}`,
    sendInput(msg) {
      const { type, x, y, key, button, deltaY } = msg;

      if (type === 'mouseMove') {
        sendX11(this.display, 'move', x, y);
      }
      if (type === 'mouseDown') {
        sendX11(this.display, 'click', x, y, button);
      }
      if (type === 'keyDown') {
        sendX11(this.display, 'key', key);
      }
      if (type === 'scroll') {
        sendX11(this.display, 'scroll', x, y, deltaY);
      }
    },
    stop() { /* cleanup */ }
  };
}

x11-input.py (XTest)

from Xlib import X, display
from Xlib.ext import xtest

d = display.Display(':100')
root = d.screen().root

def mouse_move(x, y):
    xtest.fake_input(d, X.MotionNotify, x=x, y=y)
    d.sync()

def mouse_click(x, y, button=1):
    xtest.fake_input(d, X.ButtonPress, button=button)
    xtest.fake_input(d, X.ButtonRelease, button=button)
    d.sync()

def key_press(keycode):
    xtest.fake_input(d, X.KeyPress, keycode=keycode)
    xtest.fake_input(d, X.KeyRelease, keycode=keycode)
    d.sync()

API de Input

POST /api/input

Envia um evento único de input.

// Request
POST /api/input
Authorization: Bearer {token}
{
  "sessionId": "uuid",
  "type": "mouseMove",
  "x": 640,
  "y": 360
}

POST /api/input/batch

Envia múltiplos eventos em uma requisição (otimização).

// Request
POST /api/input/batch
Authorization: Bearer {token}
{
  "sessionId": "uuid",
  "actions": [
    {"type": "mouseMove", "x": 100, "y": 100},
    {"type": "mouseDown", "button": 1},
    {"type": "mouseUp", "button": 1}
  ]
}
