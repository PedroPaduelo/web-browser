🖱️ Sistema de Input Relay

Visão Geral

O sistema de input relay permite que eventos de mouse e teclado capturados no navegador do cliente sejam injetados no Xvfb (display remoto). Utiliza a extensão XTest do X11 via Python.

Input Mapper

O input-mapper.ts normaliza os eventos do DOM do navegador para o sistema X11:

Transformações

  • Coordenadas: Canvas (CSS pixels) → Display X11 (físico)
  • Botões mouse: 0=left, 1=middle, 2=right
  • Teclas: keyCode → keySym do X11
  • Scroll: wheel → button 4/5
  • 🔄 Fluxo Completo

Exemplo de Mapping

// DOM Event → formato interno
{
  "type": "mouse_move",
  "x": 500,     // canvas coordinates
  "y": 300,
  "button": 0,
  "buttons": 1
}

// Mapeado para X11:
{
  "type": "mouse_move",
  "x": 1000,    // X11 display coords (2x for highDPI)
  "y": 600,
  "button": 1   // X11 button 1 = left click
}

WebSocket Input

Os eventos são enviados via WebSocket (tópico "input") para o servidor:

// Exemplo de mensagem enviada
{
  "type": "input",
  "sessionId": "abc123",
  "data": {
    "type": "mouse_click",
    "x": 512,
    "y": 384,
    "button": 0
  }
}

Input Handler (Node.js)

Recebe mensagens WebSocket com tipo "input" e redireciona para o processo Python:

  • Mantém um pipe com o daemon Python por sessão
  • Serializa eventos como JSON línea por línea
  • Dá flush após cada evento
  • Log erros caso processo morra
  • 🔄 Fluxo Completo

Python Daemon (x11-input.py)

Processo Python que usa python-xlib para injetar eventos no Xvfb:

#!/usr/bin/env python3
import json
import sys
from Xlib import X, display
from Xlib.ext import xtest

DISPLAY = ":99"
dpy = display.Display(DISPLAY)

def mouse_move(x, y):
    xtest.fake_input(dpy, X.MotionNotify, x, y)

def mouse_click(button):
    # button 1 = left, 2 = middle, 3 = right
    xtest.fake_input(dpy, X.ButtonPress, button)
    xtest.fake_input(dpy, X.ButtonRelease, button)

def key_down(keysym):
    keycode = dpy.keysym_to_keycode(keysym)
    xtest.fake_input(dpy, X.KeyPress, keycode)

def key_up(keysym):
    keycode = dpy.keysym_to_keycode(keysym)
    xtest.fake_input(dpy, X.KeyRelease, keycode)

# Loop lendo stdin (JSON)
for line in sys.stdin:
    event = json.loads(line)
    handle_event(event)
    dpy.sync()

Tipos de Eventos

Tipo Params Ação X11
mouse_move x, y MotionNotify
mouse_click button ButtonPress + ButtonRelease
mouse_down button ButtonPress
mouse_up button ButtonRelease
mouse_wheel delta Button 4 (up) / 5 (down)
key_down key KeyPress
key_up key KeyRelease

Fluxo de Dados

1 DOM Event click, keydown, mousemove
→
2 Mapper Normaliza coord & botões
→
3 WS Send Envia JSON via WebSocket
→
4 Handler Recebe e pipe para Python
→
5 XTest Injeta no Xvfb

Latência

  • Browser → WS: ~10-30ms
  • WS → Python: ~1-5ms (pipe local)
  • Python → X11: ~5-15ms (XTest fake input)
  • Total: ~20-50ms
  • 🔄 Fluxo Completo

Pontos de Falha

  • 🔴 python-xlib ausente: Sistema operacional não tem X11 libs
  • 🔴 Xvfb não acessível: DISPLAY :99 não existe
  • 🟡 Sincronização: Eventos podem chegar fora de ordem
  • 🟡 Escala: Muitos eventos simultâneos podem causar lag
