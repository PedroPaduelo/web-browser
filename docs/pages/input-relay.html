Input Relay (Mouse e Teclado)

Visao Geral

O sistema de input captura eventos de mouse e teclado do browser do usuario, serializa em JSON, envia via WebSocket ou HTTP, e injeta no display virtual X11 usando Python com python-xlib.

Pipeline de Input

Browser (DOM Events)
    |  mousedown, mouseup, mousemove, wheel, keydown, keyup
    |
    v
input-mapper.ts (Frontend)
    |  Converte DOM events em formato padronizado
    |  Calcula coordenadas relativas ao canvas
    |
    v
WebSocket /ws/input (JSON)
    |  ou POST /api/input (HTTP fallback)
    |  ou POST /api/input/batch (multiplos)
    |
    v
InputHandler (input-handler.js)
    |  Spawna: python3 x11-input.py
    |  DISPLAY=:{displayNum}
    |  Envia JSON por stdin (newline-delimited)
    |
    v
Python x11-input.py
    |  python-xlib + xdotool
    |  XTest para injetar eventos X11
    |
    v
Xvfb Display -> Chrome processa o evento

Tipos de Input

Cada evento e enviado como um objeto JSON. Os tipos suportados sao:

mousemove

{ "type": "mousemove", "x": 640, "y": 360 }

mousedown / mouseup

{ "type": "mousedown", "button": "left" }
{ "type": "mouseup", "button": "left" }
// Botoes: "left", "middle", "right"

wheel (scroll)

{ "type": "wheel", "deltaY": -120 }
// deltaY negativo = scroll para cima

keypress

{ "type": "keypress", "code": "KeyA", "shift": false, "ctrl": false }

type (texto livre)

{ "type": "type", "text": "hello world" }

Endpoints

Metodo Rota Body Descricao
POST/api/input{ sessionId, type, ... }Enviar um evento
POST/api/input/batch{ sessionId, actions: [...] }Enviar multiplos eventos
WS/ws/inputJSON por mensagemStreaming de input em tempo real

X11 Input Handler

  • Arquivo: server/x11-input.py
  • Entrada: Le JSON line-by-line do stdin
  • Conexao: Usa python-xlib para conectar ao display X11
  • Injecao: XTest extension para injetar eventos sinteticos
  • Mouse: move, click (1=left, 2=middle, 3=right), scroll (4=up, 5=down)
  • Teclado: keypress com suporte a modificadores (shift, ctrl, alt)
  • Ciclo de vida: Um processo spawna por sessao e vive ate a sessao ser encerrada

Frontend

  • input-mapper.ts: Converte clientX/Y em coordenadas do canvas (considerando scale e offset)
  • useSession hook: Gerencia conexao WebSocket dedicada para input
  • Eventos capturados: mousedown, mouseup, mousemove, wheel, keydown, keyup
  • Prevencao: Eventos padrao do browser sao bloqueados (scroll da pagina, context menu do botao direito)
