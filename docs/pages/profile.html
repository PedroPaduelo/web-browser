Profile Manager

Gerencia cookies, localStorage e outros dados de sessão do Chrome. Permite persistir estado entre múltiplas sessões do mesmo tenant.

Estrutura de Armazenamento

data/
└── tenants/
    └── {tenantId}/
        ├── profiles/
        │   ├── Default/           ← Chrome Default profile
        │   │   ├── Cookies
        │   │   ├── Local Storage/
        │   │   ├── Session Storage/
        │   │   ├── IndexedDB/
        │   │   └── Preferences
        │   └── metadata.json      ← Metadata (last updated)
        └── sessions/
            └── {sessionId}/
                └── {cache, logs, etc}

Operações Principais

📋

GET /api/profile

Retorna se existe profile e metadados.

{
  "exists": true,
  "metadata": {
    "createdAt": "2025-03-17T...",
    "updatedAt": "2025-03-19T...",
    "size": "4.2MB"
  }
}
🗑️

DELETE /api/profile

Remove profile do tenant (cookies, storage).

{ "message": "Profile cleared" }
📦

Profile Copy

Ao criar sessão, o profile é copiado para data/tenants/{tid}/sessions/{sid}/.

const userDataDir = tenantManager
  .copyProfileToSession(tenantId, sessionId);
💾

Profile Merge

Ao encerrar sessão (não timeout), diffs são aplicados no profile principal.

tenantManager.mergeProfileFromSession(
  tenantId, sessionId
);

Save Session State

O perfil do Chrome é sensível a mudanças externas. O profile-manager.js usa x11-input.py para escrever arquivo Preferences com configurações válidas. 

async function saveSessionState(tenantId, displayNum) {
  const x11 = new X11Input(`:${displayNum}`);
  await x11.send('write_preferences', {
    'session.restore_on_startup': 4,
    'session.startup_urls': []
  });
  await x11.send('quit_chrome'); // Graceful quit
  await x11.close();
}

Uso no Frontend

// src/lib/auth-client.ts
export async function getProfileInfo() {
  const res = await authFetch('/api/profile');
  return res.json(); // { exists, metadata }
}

export async function clearProfile() {
  await authFetch('/api/profile', { method: 'DELETE' });
}

// No componente:
useEffect(() => {
  getProfileInfo().then(info => setHasProfile(info.exists));
}, []);
