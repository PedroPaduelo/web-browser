👤 Gerenciamento de Profiles

O que é um Profile?

Um profile armazena dados persistentes de navegação: cookies, localStorage, cache, histórico. Permite que sessões temporárias tenham dados lembrados entre execuções.

Master Session

Existe um conceito de sessão master por tenant:

  • Sessão dedicada cujo Xvfb NÃO é destruído
  • Todas as outras sessões podem "clonar" esse profile
  • Ideal para manter logins de sites complexos (ex: Gmail)
  • 🔄 Fluxo Completo

Local de Armazenamento

Tipo Localização (no Xvfb) Tamanho
Cookies $HOME/.config/google-chrome/Default/Cookies ~2-10 MB
LocalStorage $HOME/.config/google-chrome/Local Storage/ ~1-5 MB
Cache $HOME/.cache/google-chrome/Default/Cache ~50-200 MB
History $HOME/.config/google-chrome/Default/History ~10-50 MB

Nota: Os dados são armazenados dentro do filesystem do Xvbf display e copiados quando necessário para sessões clonadas.

Profile Manager

O módulo profile-manager.js gerencia:

  • Identificação de perfil existente (arquivos Cookies + Local Storage)
  • Criação de "master session" se profile novo
  • Cópia de arquivos entre Xvfb displays
  • Exclusão segura de perfis antigos
  • Migração de dados entre tenants (se necessário)
  • 🔄 Fluxo Completo

Endpoints de Profile

Método Rota Descrição
GET /api/profile Verifica se existe profile salvo
DELETE /api/profile Remove todos os dados do profile

Segurança

  • 🟡 Isolamento: Cada tenant tem profile separado
  • 🟡 Cleanup: Profiles devem ser limpos ao deletar tenant
  • 🔴 Sensitive data: Cookies podem conter sessões ativas → precisa criptografia at rest
  • 🔄 Fluxo Completo

Comandos de Manutenção

# Listar perfis de todos os tenants
find /data/profiles -type d -ls

# Limpar profile específico
rm -rf /data/profiles/{tenantId}/master

# Limpar todos os profiles antigos (> 90 dias)
find /data/profiles -mtime +90 -type d -exec rm -rf {} \;

# Verificar tamanho por tenant
du -sh /data/profiles/*/master

Limitações

  • Profiles grandes (> 500 MB) podem causar lentidão na cópia
  • Não há versionamento — toda cópia é full
  • Perfil "poluído" por navegação pode afetar sessões clonadas
  • Recomendado: rotacionar profiles a cada X dias
