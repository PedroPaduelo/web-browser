Profiles Persistentes

Visao Geral

Cada tenant possui um "master profile" do Chrome que persiste entre sessoes. Quando uma sessao inicia, o profile master e copiado para a sessao. Quando a sessao encerra, as mudancas sao mescladas de volta ao master.

Isso garante que cookies, logins salvos, preferencias e bookmarks sejam mantidos entre sessoes diferentes do mesmo tenant.

Arquitetura de Profiles

/data/tenants/{tenantId}/
|-- profile-master/           <-- Profile persistente (merge de todas as sessoes)
|   |-- Default/
|       |-- Cookies
|       |-- Preferences
|       |-- Bookmarks
|       |-- Login Data
|       |-- Web Data
|       |-- Local State
|-- sessions/
|   |-- {sessionId}/
|       |-- profile/          <-- Copia isolada por sessao
|           |-- Default/
|-- metadata.json             <-- Metadados do tenant

Ciclo de Vida do Profile

1
Sessao Criada
Copia master para session/profile
2
Sessao Ativa
Chrome usa session/profile isolado
3
Sessao Encerra
Merge session de volta ao master
4
Proxima Sessao
Comeca com master atualizado

Arquivos Sincronizados

Arquivo Conteudo
CookiesCookies de sessao e persistentes
PreferencesConfiguracoes do Chrome
BookmarksFavoritos
Login DataSenhas salvas (criptografado pelo Chrome)
Web DataFormularios auto-complete
Local StateEstado global do Chrome

API de Profile

GET /api/profile

{
  "exists": true,
  "metadata": {
    "tenantId": "a1b2c3d4e5f6g7h8",
    "savedAt": "2025-03-10T14:30:00Z",
    "version": "2.0",
    "lastActivity": "2025-03-12T09:15:00Z"
  }
}

DELETE /api/profile

Limpa todo o profile do tenant (master + sessions). Retorna { ok: true }.

Profile Manager

Classe ProfileManager (profile-manager.js) responsavel pela gestao de profiles persistentes.

Metodos

  • hasProfile(tenantId) -- Verifica se existe profile salvo
  • loadMetadata(tenantId) -- Carrega metadados do profile
  • saveMetadata(tenantId, extra) -- Salva/atualiza metadados
  • cleanProfile(tenantId) -- Remove profile completo do tenant

Metadata v2.0

  "tenantId": "a1b2c3d4e5f6g7h8",
  "savedAt": "2025-03-10T14:30:00Z",
  "version": "2.0",
  "lastDisplay": ":101",
  "lastActivity": "2025-03-12T09:15:00Z"
}

Tenant Manager (Profile)

Funcoes do tenant-manager.js relacionadas a profiles:

  • ensureTenantDir(tenantId) -- Cria estrutura de diretorios do tenant
  • getProfileMasterDir(tenantId) -- Retorna caminho do profile master
  • copyProfileToSession(tenantId, sessionId) -- Copia master para sessao
  • mergeProfileFromSession(tenantId, sessionId) -- Merge sessao de volta ao master
  • cleanupSessionDir(tenantId, sessionId) -- Remove diretorio da sessao

Importante: O merge e seletivo -- apenas arquivos essenciais (Cookies, Preferences, Bookmarks, Login Data, Web Data, Local State) sao copiados, nao todo o profile.
