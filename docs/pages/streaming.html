🎬 Sistema de Streaming de Vídeo

Visão Geral

O streaming de vídeo do Serende utiliza FFmpeg para capturar a tela do Xvfb via x11grab e codificar em MJPEG (Motion JPEG) para transmissão via WebSocket.

Arquitetura do Streaming

┌─────────────────────────────────────────────────────────────────────┐
│                        Xvfb (:99)                                   │
│                         ┌─────────────┐                              │
│                         │ Chrome      │                              │
│                         │ Headless    │                              │
│                         └─────────────┘                              │
└──────────────────────────┼──────────────────────────────────────────┘
                           │ X11 Display
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│  FFmpeg                                                              │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ ffmpeg -f x11grab -video_size 1920x1080 -i :99               │ │
│  │   -c:v mjpeg -q:v 2 -update 1 -f mjpeg                        │ │

└──────────────────────────┼──────────────────────────────────────────┘

                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│  Stream Manager                                                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐              │
│  │ SOI Marker  │→ │ JPEG Data   │→ │ EOI Marker  │              │

Comando FFmpeg

ffmpeg \
  -f x11grab \
  -video_size 1920x1080 \
  -framerate 30 \
  -i :99 \
  -c:v mjpeg \
  -q:v 2 \
  -update 1 \
  -f mjpeg \
  tcp://localhost:5000

Parâmetros

Parâmetro Descrição
-f x11grab Formato de captura de tela X11
-video_size Resolução do capture
-framerate Taxa de quadros (30 fps)
-c:v mjpeg Codec MJPEG (sem compressão perceptiva)
-q:v 2 Qualidade JPEG (1-31, menor = melhor)
-update 1 Atualiza mesma imagem (single-frame)

Stream Manager

O stream-manager.js extrai frames MJPEG e distribui para clientes WebSocket:

  • Conecta no TCP do FFmpeg via net.Stream
  • Parser de MJPEG com marcadores SOI/EOI
  • Buffers de frame individuais
  • Broadcast para múltiplos clientes
  • Reconexão automática em caso de falha
  • 🔄 Fluxo Completo

Formato MJPEG

┌─────────┬─────────┬─────────┬─────────┬─────────┐
│  SOI   │ APP0   │  DQT   │  SOF0  │  DHT   │  ...  │  EOI  │
│0xFFD8  │ marker │  table │ frame  │ table  │ data │0xFFD9│
└─────────┴─────────┴─────────┴─────────┴─────────┘
   2 bytes  2 bytes       JPEG compressed frame data
  • SOI (Start of Image): 0xFFD8
  • EOI (End of Image): 0xFFD9
  • Cada frame é um JPEG completo e independente
  • 🔄 Fluxo Completo

Fluxo de Dados

1 FFmpeg Captura X11 → codifica MJPEG
→
2 TCP Stream Envia frames via TCP
→
3 Parser Extrai JPEG com SOI/EOI
→
4 Broadcast Envia a todos WS clientes
→
5 Canvas drawImage() → renderiza

Performance

Métrica Valor Típico Notas
Latência 50-150ms Depende da taxa de quadros
Bandwidth 1-5 MB/s Depende da complexidade da página
CPU (servidor) 10-30% Para 1 sessão 1080p @ 30fps
Qualidade q:v 2 Boa qualidade com compressão leve

Browser Client (Frontend)

O hook useStream.ts processa o streaming no browser:

// Simplified
wsClient.onBinary((data) => {
  // data é um ArrayBuffer com o JPEG completo
  const blob = new Blob([data], { type: 'image/jpeg' })
  const url = URL.createObjectURL(blob)
  const img = new Image()
  img.onload = () => {
    ctx.drawImage(img, 0, 0)
    URL.revokeObjectURL(url)
  }
  img.src = url
})
