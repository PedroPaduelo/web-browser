MCP Server Integration

Model Context Protocol server expõe ferramentas de navegação remota para Claude Desktop e IDEs compatíveis.

O que é MCP?

O Model Context Protocol (MCP) permite que LLMs acessem ferramentas externas de forma padronizada. O Serende expõe um servidor MCP que permite ao Claude controlar navegadores remotos.

🎯 Tools

create_session, navigate, click, type, screenshot

🔌 Transport

stdio (Claude Desktop) ou http/sse (servidor remoto)

🤝 Context

Compartilha tokens e URLs automaticamente

Ferramentas MCP Disponíveis

Tool Parâmetros Descrição
serende_create_session{url, resolution}Cria nova sessão Chrome
serende_close_session{sessionId}Encerra sessão
serende_navigate{sessionId, url}Navega para URL
serende_click{sessionId, x, y, button}Clique em coordenadas
serende_type{sessionId, text}Digita texto
serende_screenshot{sessionId}Captura screenshot (base64)
serende_get_info{sessionId}Retorna URL, título

Configuração Claude Desktop

// ~/.config/claude-desktop/claude_desktop_config.json
{
  "mcpServers": {
    "serende": {
      "command": "npx",
      "args": ["-y", "@serende/mcp-server"],
      "env": {
        "SERENDE_API_URL": "http://localhost:4201",
        "SERENDE_API_KEY": "sk-xxx"
      }
    }
  }
}

Exemplo de Uso

No Claude Desktop, após configurar o MCP server:

User: Abra uma sessão do navegador em https://google.com

Claude: Vou criar uma sessão remota.
└─ serende_create_session(url="https://google.com")

[Claude pode então usar click, type, navigate...]

User: Clique no botão de busca e digite "teste"

Claude:
└─ serende_click(sessionId, x=500, y=300)
└─ serende_type(sessionId, text="teste")
