Sistema de Audio

Visao Geral

O audio do Chrome no Xvfb e capturado via PulseAudio virtual e transmitido como PCM raw via WebSocket para o browser, onde e reproduzido pela Web Audio API.

Pipeline de Audio

Chrome (Xvfb)
    |  Audio via PulseAudio
    v
PulseAudio (Virtual Sink)
    |  parec --format=s16le --rate=44100 --channels=2
    v
WebSocket /ws/audio (binario)
    |  PCM raw frames (s16le, 44100Hz, stereo)
    v
Web Audio API (Browser)
    |  AudioContext.decodeAudioData()
    |  ou AudioWorklet (baixa latencia)
    v
Speaker output

Configuracao

Parametro Valor
FormatoPCM signed 16-bit little-endian (s16le)
Sample Rate44100 Hz
Canais2 (stereo)
TransporteWebSocket binario
Latencia alvo< 200ms

Status da Implementacao

Implementacao Parcial

  • Audio esta implementado parcialmente
  • PulseAudio precisa estar configurado no container
  • Web Audio API requer interacao do usuario para iniciar (autoplay policy)
  • Fallback: sem audio se PulseAudio nao disponivel
