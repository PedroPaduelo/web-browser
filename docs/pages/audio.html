🔊 Sistema de Áudio

Visão Geral

O sistema de áudio captura som do Xvfb (PulseAudio) e transmite via WebSocket em formato PCM raw, sendo reproduzido no browser via Web Audio API.

Arquitetura do Áudio

┌─────────────────────────┐
│  Chrome (Xvfb)          │
│  Toca áudio de sites    │
│  (YouTube, Spotify)     │
└──────────┬──────────────┘
           │ PulseAudio (virtual sink)
           ▼
┌─────────────────────────┐
│  Audio Manager          │
│  (audio-manager.js)     │
│  FFmpeg captura pulse   │
│  -f pulse -i default    │
│  Codifica PCM s16le     │
│  Mono 44100 Hz          │
└──────────┬──────────────┘
           │ Binary (PCM)
           ▼
┌─────────────────────────┐
│  WebSocket Server       │
│  Broadcast binário      │
│  para todos os clientes │
└──────────┬──────────────┘
           │ WS Binary
           ▼
┌─────────────────────────┐
│  Browser Client         │
│  useAudio.ts            │
│  AudioContext API        │
│  Float32Array → buffer  │
│  → AudioBufferSource    │
└─────────────────────────┘

Captura (Servidor)

O audio-manager.js usa FFmpeg para capturar áudio do PulseAudio:

ffmpeg \
  -f pulse \
  -i default \
  -ac 1 \           # Mono
  -ar 44100 \       # 44.1 kHz
  -f s16le \        # PCM signed 16-bit little-endian
  -acodec pcm_s16le \
  pipe:1            # Output para stdout

Reprodução (Browser)

O hook useAudio.ts recebe chunks PCM via WebSocket e reproduz via Web Audio API:

// Simplificado
const audioCtx = new AudioContext({ sampleRate: 44100 })

ws.onBinary((data: ArrayBuffer) => {
  // Converte Int16 → Float32
  const int16 = new Int16Array(data)
  const float32 = new Float32Array(int16.length)
  for (let i = 0; i < int16.length; i++) {
    float32[i] = int16[i] / 32768.0
  }

  // Cria buffer de áudio
  const buffer = audioCtx.createBuffer(1, float32.length, 44100)
  buffer.getChannelData(0).set(float32)

  // Reproduz
  const source = audioCtx.createBufferSource()
  source.buffer = buffer
  source.connect(audioCtx.destination)
  source.start()
})

Formato PCM

Propriedade Valor
EncodingPCM signed 16-bit little-endian (s16le)
Canais1 (Mono)
Sample Rate44100 Hz
Bit Depth16 bits
Chunk Size~4096 bytes (2048 samples)
Latência~50-100ms

Pontos de Falha

  • 🔴 PulseAudio não disponível: Sem áudio se não houver sink virtual
  • 🟡 Buffer underrun: Atrasos na rede causam silêncio ou cliques
  • 🟡 AutoPlay bloqueado: Browsers exigem interação antes de tocar áudio
  • 🟡 Sincronização A/V: Áudio e vídeo podem dessincronizar
