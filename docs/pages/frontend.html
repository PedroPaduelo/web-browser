Hooks Principais

useSession

Gerencia estado da sessão (idle, creating, active, destroying).

const { status, sessionInfo, createSession, destroySession } = useSession();

return (
   createSession({ resolution: res, startUrl: url })}
    onStop={destroySession}
  />
);

useStream

Conecta ao WebSocket de stream e renderiza no canvas.

const { isConnected, fps } = useStream(isActive, sessionId);

// Internamente:
const ws = new WebSocket(`${WS_URL}/ws/stream?sessionId=...`);
ws.onmessage = (event) => {
  createImageBitmap(event.data).then(bitmap => {
    ctx.drawImage(bitmap, 0, 0);
  });
};

usePageInfo

Busca URL e título da página ativa via API.

const { pageInfo, refetch } = usePageInfo(sessionId);

// GET /api/session/{id}/page
// { url, title, favicon }

useInputRelay

Converte eventos do canvas em chamadas API.

useInputRelay(canvasRef, containerRef, true, resolution, sessionId);

// Captura: mousemove, mousedown, mouseup, keydown, wheel
// Envia via POST /api/input

Fluxo de Input no Frontend

  1. Usuário move mouse sobre o canvas
  2. handleMouseMove calcula posição relativa ao canvas (coordenadas normalizadas)
  3. Chama sendInput({ type: 'mouseMove', x, y })
  4. authFetch('/api/input', { method: 'POST', body })
  5. Backend recebe, valida, encaminha ao X11 input handler
  6. Chrome recebe evento X11 na display virtual
  7. Cursor local (SVG) move instantaneamente, sem esperar round-trip
