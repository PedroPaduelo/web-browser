Componentes

App.tsx

Root component. Gerencia estado de autenticacao, sessao ativa e stream. Condiciona renderizacao: exibe LoginScreen se nao autenticado, ou BrowserViewer com SessionControls quando autenticado.

BrowserViewer.tsx

Canvas HTML5 que renderiza frames JPEG recebidos via WebSocket. Captura eventos de mouse (click, move, scroll) e teclado (keydown, keyup) e os envia pelo input relay. Escala automatica para manter aspect ratio.

SessionControls.tsx

Controles de sessao: botoes start/stop, seletor de resolucao (1280x720, 1920x1080), campo de URL inicial, timer visual de timeout mostrando tempo restante.

LoginScreen.tsx

Formulario de login com campo para API key. Chama auth-client.login() e exibe erros inline. Redireciona para o viewer apos autenticacao bem-sucedida.

ConnectionStatus.tsx

Indicador visual no canto superior: FPS atual do stream, estado da conexao WebSocket (connected/reconnecting/disconnected), latencia estimada.

Hooks

  • useSession(): Gerencia o ciclo de vida completo da sessao. Metodos para create (POST /api/session), destroy (DELETE /api/session/:id), polling de status, e controle de timeout. Retorna sessionId, status e funcoes de controle.
  • useStream(): Conecta ao WebSocket /ws/stream, recebe frames JPEG como ArrayBuffer, decodifica via createImageBitmap() e renderiza no canvas 2D. Gerencia reconexao automatica.
  • useAuth() (AuthProvider): Context provider que gerencia estado de autenticacao global. Expoe login(), logout(), isAuthenticated, tenantInfo. Persiste token no localStorage.

Bibliotecas Client

auth-client.ts

Modulo de autenticacao client-side com as seguintes funcoes:

  • login(apiKey) -- POST /api/auth/login, armazena JWT no localStorage
  • logout() -- Remove token e limpa estado
  • getToken() -- Retorna JWT atual do localStorage
  • authFetch(url, opts) -- Wrapper do fetch que injeta Authorization header
  • getAuthWsUrl(path, sessionId) -- Gera URL WebSocket com token e sessionId como query params
  • getProfileInfo() -- GET /api/profile com auth
  • clearProfile() -- DELETE /api/profile com auth

ws-client.ts

Classe WsClient com reconexao automatica:

  • connect(url) -- Abre conexao WebSocket
  • disconnect() -- Fecha conexao limpa
  • send(data) -- Envia JSON serializado
  • onMessage(cb) -- Handler para mensagens JSON
  • onBinary(cb) -- Handler para dados binarios (JPEG frames)
  • onAuthFail(cb) -- Handler para close code 4001 (token expirado)
  • Reconexao automatica: ate 10 tentativas, backoff de 1s a 5s

Renderizacao de Video

Pipeline de renderizacao de video em tempo real via WebSocket:

1. WebSocket recebe ArrayBuffer (frame JPEG)
2. new Blob([arrayBuffer], { type: 'image/jpeg' })
3. createImageBitmap(blob)  // decode async, off main thread
4. canvas.getContext('2d').drawImage(bitmap, 0, 0, w, h)
5. Escala automatica para manter aspect ratio
6. ~30 FPS em tempo real

O uso de createImageBitmap() ao inves de new Image() evita blocking na thread principal e elimina a necessidade de URL.createObjectURL() / URL.revokeObjectURL().

Build

  • Desenvolvimento: npx vite --host 0.0.0.0 --port 5173 -- HMR habilitado, proxy para API backend
  • Build: npx vite build -- Gera bundle otimizado em dist/
  • Producao: Servido por Express via express.static('dist') no mesmo servidor do backend
  • Porta de producao: 4201 (backend + frontend no mesmo processo)
