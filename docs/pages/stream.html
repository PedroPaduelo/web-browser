Stream de Vídeo

O sistema usa Chrome DevTools Protocol (CDP) para capturar screenshots do navegador em tempo real. Os frames JPEG são transmitidos via WebSocket para o frontend.

Fluxo CDP Screencast

Código: CDPScreencast

class CDPScreencast {
  constructor(cdpPort) {
    this.cdpPort = cdpPort;
    this.ws = null;
    this.frameCount = 0;
  }

  start(onFrame) {
    this.onFrame = onFrame;
    this._connect();
  }

  async _connect() {
    // 1. Get WebSocket URL from CDP
    const res = await fetch(`http://127.0.0.1:${this.cdpPort}/json`);
    const targets = await res.json();
    const page = targets.find(t => t.type === 'page');
    const wsUrl = page.webSocketDebuggerUrl;

    // 2. Connect WebSocket
    this.ws = new WebSocket(wsUrl);

    this.ws.on('open', () => {
      // 3. Enable Page events
      ws.send(JSON.stringify({ id: 1, method: 'Page.enable' }));
    });

    this.ws.on('message', (raw) => {
      const msg = JSON.parse(raw);

      // 4. Start screencast after Page.enable
      if (msg.id === 1 && msg.result) {
        ws.send(JSON.stringify({
          id: 2,
          method: 'Page.startScreencast',
          params: { format: 'jpeg', quality: 80, everyNthFrame: 1 }
        }));
      }

      // 5. Receive frame
      if (msg.method === 'Page.screencastFrame') {
        const { data: b64 } = msg.params;
        const frame = Buffer.from(b64, 'base64');
        this.onFrame(frame);
        this.frameCount++;

        // 6. ACK required!
        ws.send(JSON.stringify({
          id: 3,
          method: 'Page.screencastFrameAck',
          params: { sessionId: msg.params.sessionId }
        }));
      }
    });
  }
}

StreamManager (Broadcast)

Push Frame

O CDPScreencast chama pushFrame() para cada frame JPEG.

pushFrame(frameBuffer) {
  this.lastFrame = frameBuffer;
  this.broadcastFrame(frameBuffer);
}

Broadcast

Envia para todos os clientes WebSocket conectados, com controle de backpressure.

broadcastFrame(frame) {
  for (const ws of this.clients) {
    // Skip cliente lento (>4MB buffer)
    if (ws.bufferedAmount > 4 * 1024 * 1024) continue;
    ws.send(frame, { binary: true });
  }
}

// useStream.ts hook
const ws = new WebSocket(`wss://server/api/stream/${sessionId}`);

ws.onmessage = (event) => {
  const blob = event.data;

  // Create ImageBitmap from JPEG
  createImageBitmap(blob).then((bitmap) => {
    ctx.drawImage(bitmap, 0, 0);
    bitmap.close();
  });
};
