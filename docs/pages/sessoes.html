Gerenciamento de Sessões

O Session Manager controla a criação, monitoramento e destruição de sessões Chrome. Cada sessão roda em um display Xvfb isolado com profile persistente.

Ciclo de Vida de uma Sessão

1

Criação

POST /api/session → startSession()

  • • Alloca display :100-199
  • • Inicia Xvfb
  • • Copia profile
  • • Inicia Chrome com CDP
2

Ativa

Sessão rodando

  • • Chrome + Xvfb ativos
  • • CDP conectado
  • • StreamManager ativo
  • • Timeout tracker
3

Timeout

30min inativo

  • • Verificação a cada min
  • • lastActivity timestamp
  • • auto stopSession()
  • • merge profile
4

Encerrada

DELETE /api/session

  • • Mata Chrome
  • • Mata Xvfb
  • • Release display
  • • Cleanup
5

Crash

Health check fail

  • • Monitor 30s
  • • exitCode check
  • • auto stop
  • • callback

Código: startSession

async function startSession(sessionId, tenantId, options = {}) {
  // 1. Limites
  if (sessions.size >= MAX_SESSIONS) throw new Error('Global limit reached');
  const tenantCount = getTenantSessionCount(tenantId);
  if (tenantCount >= effectiveMax) throw new Error('Tenant limit reached');

  // 2. Display allocation
  const displayNum = allocateDisplay(); // :100-199
  const cdpPort = CDP_BASE_PORT + (displayNum - DISPLAY_MIN);

  // 3. Profile setup
  const userDataDir = tenantManager.copyProfileToSession(tenantId, sessionId);

  // 4. Start Xvfb
  const xvfb = spawn('Xvfb', [display, '-screen', '0', `${res}x24`, ...]);

  // 5. Start Chrome
  const chrome = spawn(CHROME_BIN, {
    DISPLAY: display,
    '--remote-debugging-port': cdpPort,
    '--user-data-dir': userDataDir,
    '--app': startUrl,
  });

  // 6. Wait CDP
  const cdpUrl = await waitForCDP(cdpPort);

  // 7. Health check (30s interval)
  const healthCheckInterval = setInterval(() => {
    if (xvfb.killed || chrome.killed) {
      stopSession(sessionId, 'died');
    }
  }, 30000);

  // 8. Save session
  sessions.set(sessionId, { xvfb, chrome, cdpUrl, ... });
  return { sessionId, cdpUrl, resolution };
}

Sistema de Timeout

Atividade

Cada request ao /api/** dispara trackActivity() que chama sessionManager.updateActivity(sessionId).

function trackActivity(req, res, next) {
  const { sessionId } = req.params;
  if (sessionId) {
    sessionManager.updateActivity(sessionId);
  }
  next();
}

Verificação

O timeout roda em intervalos de 1 minuto. Verifica Date.now() - lastActivity.

function checkTimeout() {
  const inactive = Date.now() - session.lastActivity;
  if (inactive >= SESSION_TIMEOUT_MS) {
    stopSession(sessionId, 'timeout');
  }
}

Display Allocation

Range de Displays

Displays virtuais Xvfb usam números 100-199, permitindo até 100 sessões simultâneas por instância.

const DISPLAY_MIN = 100;
const DISPLAY_MAX = 199;

function allocateDisplay() {
  for (let d = DISPLAY_MIN; d <= DISPLAY_MAX; d++) {
    if (!usedDisplays.has(d)) {
      usedDisplays.add(d);
      return d;
    }
  }
  return null; // Sem displays livres
}

Cleanup

Na inicialização, o servidor limpa processos Xvfb órfãos e lock files para evitar conflitos.

execSync('pkill -f "Xvfb :[1-9][0-9][0-9]"');
for (let d = 100; d <= 199; d++) {
  unlinkSync(`/tmp/.X${d}-lock`);
  unlinkSync(`/tmp/.X11-unix/X${d}`);
}
