WebSocket

Visao Geral

O Serende usa WebSocket para dois canais de comunicacao em tempo real: streaming de video (binario) e relay de input (JSON).

Endpoints

Endpoint Autenticacao Tipo de Dados Direcao
/ws/stream?token=JWT&sessionId=ID Query param Binario (JPEG) Server → Client
/ws/input?token=JWT&sessionId=ID Query param JSON Client → Server

Protocolo de Conexao

1
HTTP Upgrade
ws://host/ws/stream?token=X&sessionId=Y
2
Validacao
Token JWT + ownership da sessao verificados
3
Handshake
WebSocket connection established
4
Streaming
Frames binarios (stream) ou JSON messages (input)

Stream WebSocket

  • Dados: JPEG frames raw (sem wrapper)
  • Tamanho: Variavel, tipico 20-100KB por frame
  • Taxa: ~30 FPS
  • Backpressure: Frame descartado se bufferedAmount > 128KB
  • Primeiro frame: Ultimo frame disponivel enviado na conexao

Input WebSocket

Mensagens JSON enviadas pelo cliente:

// Movimentacao do mouse
{ "type": "mousemove", "x": 640, "y": 360 }

// Clique
{ "type": "mousedown", "button": "left" }
{ "type": "mouseup", "button": "left" }

// Scroll
{ "type": "wheel", "deltaY": -120 }

// Tecla
{ "type": "keypress", "code": "KeyA", "shift": false, "ctrl": false }

// Digitacao de texto
{ "type": "type", "text": "hello" }

Reconexao

  • WsClient (frontend) tenta reconectar automaticamente
  • Max tentativas: 10
  • Backoff exponencial: 1s a 5s
  • Code 4001: Token expirado → para de reconectar, dispara authFail
  • Ao reconectar: recebe ultimo frame disponivel imediatamente

Token Expiry

  • Servidor verifica tokens WS a cada 60s (interval)
  • Token expirado → ws.close(4001, 'Token expired')
  • Frontend trata code 4001: para reconexao, dispara evento authFail
