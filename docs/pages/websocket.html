⚡ Comunicação WebSocket

Visão Geral

O WebSocket é o canal principal de comunicação em tempo real entre cliente e servidor, transportando:

  • Vídeo: frames MJPEG binários (stream unidirecional server → client)
  • Input: eventos de mouse/teclado JSON (client → server)
  • Controle: commands e status da sessão (ambas direções)
  • 🔄 Fluxo Completo

Cliente (ws-client.ts)

class WsClient {
  private state: ConnectionState = 'disconnected'
  private messageListeners: Set<(data:any)=>void> = new Set()
  private binaryListeners: Set<(data:ArrayBuffer)=>void> = new Set()
  private reconnectTimer: ReturnType<typeof setTimeout> | null = null

  connect(url: string) { ... }

  send(data: any) {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(typeof data === 'string' ? data : JSON.stringify(data))
    }
  }

  onMessage(fn: (data: any) => void) { ... }
  onBinary(fn: (data: ArrayBuffer) => void) { ... }
  disconnect() { ... }
}
  • Auto-reconnect com exponential backoff (1s, 2s, 4s, ..., máx 5s)
  • Max 10 tentativas de reconexão
  • Eventos de state change (conectando, conectado, reconectando, desconectado)

Servidor WebSocket

Integrado ao Express:

const wsServer = new WebSocket.Server({ server, port: 3001 })

wsServer.on('connection', (ws, req) => {
  const params = new URLSearchParams(req.url.split('?')[1])
  const token = params.get('token')
  const sessionId = params.get('sessionId')

  // Valida token
  jwt.verify(token, ...)

  // Registra cliente no Session Manager
  sessionManager.addWsClient(sessionId, ws)

  ws.on('message', (msg) => {
    // JSON: input events
    // Binário: (não usado; vídeo vem do Stream Manager)
  })

  ws.on('close', () => {
    sessionManager.removeWsClient(sessionId, ws)
  })
})

Binary Stream (Video)

Frames MJPEG são enviados como objetos ArrayBuffer via WebSocket binário:

  • Nenhum cabeçalho — o array contém JPEG completo
  • SOI (0xFFD8) e EOI (0xFFD9) marcam início/fim
  • Cliente usa Blob + URL.createObjectURL → draw no Canvas
  • 🔄 Fluxo Completo
wsClient.onBinary((data: ArrayBuffer) => {
  const blob = new Blob([data], { type: 'image/jpeg' })
  const url = URL.createObjectURL(blob)
  const img = new Image()
  img.onload = () => {
    ctx.drawImage(img, 0, 0)
    URL.revokeObjectURL(url)
  }
  img.src = url
})

Handshake e Auth

A conexão WebSocket inclui token JWT e sessionId na query string:

ws://serende.ddw1sl.easypanel.host/ws?token=eyJhbGc...&sessionId=abc123
  • Server valida JWT e extrai tenantId
  • Verifica se sessionId pertence ao tenant
  • Se inválido → close code 4001
  • 🔄 Fluxo Completo

Keepalive

Client envia keepalive a cada 30s:

{ "type": "keepalive" }

Se server não receber keepalive por 60s, desconecta cliente.

Escalabilidade

  • Cada sessão tem 1+ clientes conectados (broadcast)
  • Multi-sessões paralelas são suportadas
  • Limite prático: ~50-100 clientes simultâneos por servidor
  • Para escalar, use balanceador com sticky sessions por sessionId
