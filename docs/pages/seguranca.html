🛡️ Segurança

Visão Geral

O Serende implementa múltiplas camadas de segurança para proteger dados de tenants e prevenir ataques.

Camadas de Segurança

🔐 Autenticação

  • API Keys (SHA-256 hash)
  • JWT com expiração 24h
  • Rate limiting (5 req/min)
  • 🔄 Fluxo Completo

🔒 Autorização

  • Isolamento por tenantId
  • Session ownership validation
  • Tenant pode acessar apenas seus recursos
  • 🔄 Fluxo Completo

🛡️ Rede

  • HTTPS obrigatório
  • CORS configurável
  • WebSocket sobre TLS (WSS)
  • 🔄 Fluxo Completo

🔧 Infraestrutura

  • Chrome --no-sandbox (container)
  • XVfb isolado por sessão
  • Sem privilégios de root
  • 🔄 Fluxo Completo

API Key Security

  • Hash: API keys são hasheadas com SHA-256 antes de存储
  • Validação: Apenas o hash é guardado, nunca o valor em texto
  • Roação: Keys podem ser revogadas a qualquer momento
  • Rate limit: 5 tentativas/minuto/IP
  • 🔄 Fluxo Completo

JWT Security

  • Algoritmo: HS256 (HMAC-SHA256)
  • Expiração: 24 horas fixas
  • Secret: Variável de ambiente (NUNCA commitada)
  • Validação: server verifica assinatura + expiração em cada request
  • 🔄 Fluxo Completo

Isolamento de Sessões

Tenant A (id: tenant-a)          Tenant B (id: tenant-b)
├─ Sessions: [sess-001]           ├─ Sessions: [sess-xyz]
├─ Profile: /data/profiles/a      ├─ Profile: /data/profiles/b
├─ Xvfb: :100                     ├─ Xvfb: :200
└─ JWT: tenant=a                  └─ JWT: tenant=b

Cross-tenant protection:
- Session Manager verifica: session.tenantId === req.tenantId
- Profile Manager verifica: profile.tenantId === req.tenantId
- WebSocket valida: token.tenantId === session.tenantId

Rate Limiting

Endpoint Limite Janela
/api/auth/login 5 1 minuto
/api/sessions 10 1 minuto
Outros endpoints 100 1 minuto

Headers de Segurança

// Recomendado
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
X-XSS-Protection: 1; mode=block
Content-Security-Policy: default-src 'self'; script-src 'self'; ...
Strict-Transport-Security: max-age=31536000; includeSubDomains

Proteção contra Ataques

Ataque Mitigação
Brute Force (API Key) Rate limiting 5/min + lockout
Token Hijacking Expiração 24h + HTTPS only
Session Hijacking Validação de ownership em cada WS message
XSS (Browser Client) Sanitização de input + CSP
CSRF Same-origin policy + CSRF tokens
DoS (Session Spawn) Limite de sessões simultâneas por tenant
