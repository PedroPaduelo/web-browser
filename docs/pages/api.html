API REST Endpoints

A API Express fornece endpoints para autenticação, gerenciamento de sessões, input remoto e profile. Todos exigem JWT exceto auth.

Endpoints

🔐 Autenticação (Público)

Método Rota Descrição
POST /api/auth/login Autentica API Key → JWT
GET /api/auth/verify Verifica token JWT

💾 Profile (Auth)

Método Rota Descrição
GET/api/profileBusca status do profile
DELETE/api/profileRemove profile

📺 Sessões (Auth)

Método Rota Descrição
POST/api/sessionCria nova sessão
DELETE/api/session/:idEncerra sessão
GET/api/sessionLista sessões ativas
GET/api/session/:idDetalhes da sessão

🖱️ Input (Auth + Track)

Método Rota Descrição
POST/api/inputEnvia evento único
POST/api/input/batchEnvia batch de eventos

⚙️ Sistema

Método Rota Descrição
GET/api/healthHealth check (status, mem, sessions)
GET/api/session/:id/page(usado internamente) info da página

Middlewares Aplicados

✅ Global

  • • helmet() — Security headers
  • • cors() — CORS configurável
  • • express.json({limit: '1mb'})
  • • rateLimit() — 100 req/min
  • • requestId() — X-Request-Id

🔒 Auth

  • • authMiddleware — valida JWT
  • • Verifica tenant match (cross-tenant block)
  • • Anexa req.tenant, req.user

⏱️ Activity

  • • trackActivity — resets timeout
  • • Aplicado em rotas de input e navegação
  • • Chama sessionManager.updateActivity()

🔢 Rate Limit Login

  • • 5 tentativas por IP / minuto
  • • Map em memória (não persistente)
  • • Cleanup automático a cada 5min
