API REST

Base URL

Producao: https://serende.ddw1sl.easypanel.host

Local: http://localhost:4201

Header Authorization: Bearer {jwt_token} obrigatorio em todas as rotas (exceto health e login).

Endpoints Publicos

GET /api/health

Nao requer autenticacao.

// Response
{
  "status": "ok",
  "uptime": 12345,
  "sessions": { "active": 3, "max": 10 },
  "memory": { "rss": 150000000, "heap": 80000000 },
  "version": "2.0.0"
}

Autenticacao

POST /api/auth/login

// Request
{ "apiKey": "sk_..." }

// Response
{
  "token": "eyJ...",
  "tenantId": "a1b2...",
  "userId": "a1b2..."
}

GET /api/auth/verify

// Response
{
  "valid": true,
  "tenantId": "a1b2...",
  "userId": "a1b2..."
}

Sessoes

Metodo Rota Descricao Status
POST/api/sessionCriar sessao201
GET/api/sessionListar sessoes200
GET/api/session/:idDetalhe da sessao200
DELETE/api/session/:idEncerrar sessao200

Input

POST /api/input

// Request
{
  "sessionId": "abc123",
  "type": "keypress",
  "code": "KeyA"
}

POST /api/input/batch

// Request
{
  "sessionId": "abc123",
  "actions": [
    { "type": "mousemove", "x": 640, "y": 360 },
    { "type": "mousedown", "button": "left" },
    { "type": "mouseup", "button": "left" }
  ]
}

Browser Control (CDP)

Metodo Rota Descricao
GET/api/screenshot/:sessionIdRetorna image/jpeg
GET/api/url/:sessionIdRetorna URL atual { url }
POST/api/navigate/:sessionIdNavega para URL { url } retorna { ok, url }
POST/api/evaluate/:sessionIdExecuta script { script } retorna { result }

Admin

Requer header x-admin-secret para autenticacao de administrador.

Metodo Rota Descricao
POST/api/admin/keysCriar API key
GET/api/admin/keysListar API keys
PATCH/api/admin/keys/:idAtualizar API key
DELETE/api/admin/keys/:idRevogar API key
GET/api/admin/sessionsListar todas as sessoes
GET/api/admin/statsEstatisticas do sistema

Codigos de Erro

Status Significado
400Bad Request (payload invalido)
401Unauthorized (token invalido/ausente)
403Forbidden (sessao nao pertence ao tenant)
404Not Found (sessao/recurso inexistente)
429Too Many Requests (rate limit excedido)
500Internal Server Error
