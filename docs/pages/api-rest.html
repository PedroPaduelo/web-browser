🌐 API REST

Visão Geral

A API REST do Serende é construída com Express.js e segue convenções RESTful. Todos os endpoints (exceto login) exigem autenticação via JWT no header Authorization: Bearer {token}.

Endpoints

Método Rota Autenticação Descrição
POST/api/auth/login❌Login com API Key
GET/api/profile✅Verificar profile existente
DELETE/api/profile✅Limpar profile
POST/api/sessions✅Criar sessão
GET/api/sessions✅Listar sessões ativas
GET/api/sessions/:id✅Info da sessão
POST/api/sessions/:id/close✅Encerrar sessão
GET/api/keys✅Listar API Keys
POST/api/keys✅Criar API Key
DELETE/api/keys/:id✅Revogar API Key
GET/api/tenants✅Listar tenants
POST/api/tenants✅Criar tenant
GET/api/health❌Health check

Authentication Flow

POST /api/auth/login
Content-Type: application/json

{
  "apiKey": "123e4567-e89b-12d3-a456-426614174000"
}

← 200 OK

{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "tenantId": "456e7890-e89b-12d3-a456-426614174001",
  "expiresIn": 86400
}

Sessions Flow

POST /api/sessions
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
Content-Type: application/json

{
  "resolution": "1280x720",
  "startUrl": "https://www.google.com",
  "timeoutMs": 1800000
}

← 200 OK

{
  "sessionId": "abc123def456",
  "status": "active",
  "timeout": {
    "expiresAt": 1701234567890,
    "remaining": 1800000
  }
}

GET /api/sessions/abc123def456
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

← 200 OK

{
  "id": "abc123def456",
  "status": "active",
  "resolution": "1280x720",
  "startUrl": "https://www.google.com"
}

Error Responses

// 401 Unauthorized
{
  "error": "Invalid or missing token"
}

// 403 Forbidden
{
  "error": "Tenant inactive or expired"
}

// 404 Not Found
{
  "error": "Session not found"
}

// 429 Too Many Requests
{
  "error": "Rate limit exceeded"
}

// 500 Internal Server Error
{
  "error": "Failed to create session",
  "code": "SESSION_CREATE_FAILED"
}

Cors

API permite CORS específico para domínios configurados. Use cors() do Express com whitelist.
