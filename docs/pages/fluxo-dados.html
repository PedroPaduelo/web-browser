Backpressure & Controle de Fluxo

⚠️ Backpressure no WebSocket

O StreamManager verifica ws.bufferedAmount antes de enviar frames. Se > 4MB, o frame é descartado para evitar memória excessiva no cliente.

// stream-manager.js, linha 114
if (ws.bufferedAmount > 4 * 1024 * 1024) continue;

✅ ACK no CDP Screencast

O Chrome para de enviar frames se o ACK não for recebido. O backend envia Page.screencastFrameAck após processar cada frame.

// cdp-screencast.js, linha 101
ws.send(JSON.stringify({
  id: idCounter++,
  method: 'Page.screencastFrameAck',
  params: { sessionId },
}));
