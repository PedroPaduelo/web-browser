Multi-tenant

Visao Geral

O sistema isola cada cliente (tenant) com suas proprias sessoes, profiles e limites. O tenantId e derivado da API key via SHA256, garantindo que cada chave gere um identificador unico e deterministico.

Derivacao de TenantId

// auth.js
function deriveTenantId(apiKey) {
  return crypto.createHash('sha256')
    .update(apiKey)
    .digest('hex')
    .slice(0, 16);
}
// Resultado: 16 chars hex (ex: "a1b2c3d4e5f6g7h8")

Isolamento

Sessoes

  • Cada tenant so ve e controla suas proprias sessoes
  • Ownership check em toda operacao

Profiles

  • Diretorio isolado por tenant
  • /data/tenants/{tenantId}/

Limites

  • maxSessions por API key
  • Independente do limite global

Dados

  • Chrome userDataDir separado
  • Nenhum compartilhamento entre tenants
