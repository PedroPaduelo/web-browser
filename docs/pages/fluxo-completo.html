🔄 Fluxo Completo

Fluxo: Login → Sessao → Uso → Encerramento

Ciclo de vida completo de uma sessao Serende, do login ao cleanup final.

1
Login
Usuario insere API key no frontend (LoginScreen)
2
Auth
POST /api/auth/login valida key, retorna JWT com tenantId
3
Criar Sessao
POST /api/session com resolution e startUrl
4
Spawn
Xvfb + Chrome + FFmpeg iniciados em sequencia
5
Conectar
WS /ws/stream + /ws/input com token JWT
6
Streaming
Frames JPEG renderizados no canvas, inputs via WS
7
Uso
Navegar, clicar, digitar, scroll no browser remoto
8
Encerrar
DELETE /api/session, save profile, cleanup processos

Fluxo de Autenticacao WebSocket

Sequencia detalhada do handshake e validacao ao conectar via WebSocket:

1. Client: GET /ws/stream?token=JWT&sessionId=ID
2. Server: Parse URL, extrai token e sessionId dos query params
3. Server: verifyToken(token) ▶ payload { tenantId, iat, exp }
4. Server: getSession(sessionId) ▶ session object
5. Server: session.userId === tenantId? Sim ▶ prossegue
6. Server: wss.handleUpgrade(req, socket, head, ws)
7. Server: ws._socket.setNoDelay(true)  // desabilita Nagle
8. Server: streamManager.addClient(ws) ou inputHandler.addClient(ws)
9. Server: Registra em activeWsConnections para token check periodico

Se qualquer etapa falhar (token invalido, sessao inexistente, ownership incorreto), o socket e destruido imediatamente sem completar o upgrade.

Fluxo de Timeout

Mecanismo de timeout por inatividade que protege contra sessoes abandonadas.

1
Inatividade
30 minutos sem input de mouse/teclado ou request HTTP
2
Warning
2 minutos antes do timeout, notifica via timer no frontend
3
Timeout
Salva profile (merge com master), destroi sessao
4
Cleanup
Mata processos Chrome/FFmpeg/Xvfb, libera display e portas

Resumo dos Endpoints

Tabela completa de todos os endpoints disponibilizados pelo Serende:

Metodo Rota Auth Descricao
GET /api/health Nao Status do sistema (uptime, sessoes ativas, memoria)
POST /api/auth/login Nao Login com API key, retorna JWT
GET /api/auth/verify JWT Verificar validade do token atual
POST /api/session JWT Criar nova sessao (resolution, startUrl)
GET /api/session JWT Listar sessoes do tenant autenticado
GET /api/session/:id JWT Detalhe de uma sessao especifica
DELETE /api/session/:id JWT Encerrar sessao (save profile + cleanup)
POST /api/input JWT Enviar evento de input (mouse/teclado)
POST /api/input/batch JWT Enviar multiplos inputs em batch
GET /api/screenshot/:id JWT Capturar screenshot da sessao (JPEG)
GET /api/url/:id JWT Obter URL atual do Chrome na sessao
POST /api/navigate/:id JWT Navegar para URL especifica
POST /api/evaluate/:id JWT Executar JavaScript no contexto da pagina
GET /api/profile JWT Info do profile do tenant (tamanho, ultima sessao)
DELETE /api/profile JWT Limpar profile do tenant (cookies, cache, etc)
POST /api/admin/keys Admin Criar nova API key
GET /api/admin/keys Admin Listar todas as API keys
PATCH /api/admin/keys/:id Admin Atualizar configuracoes de uma key
POST /api/admin/keys/:id/regenerate Admin Regenerar API key (novo valor, mesmo tenant)
DELETE /api/admin/keys/:id Admin Revogar API key (enabled=0)
GET /api/admin/sessions Admin Listar todas as sessoes de todos os tenants
GET /api/admin/stats Admin Estatisticas do sistema (CPU, memoria, sessoes)
WS /ws/stream Query Stream de video (frames JPEG binarios)
WS /ws/input Query Input relay (mouse/teclado via JSON)
