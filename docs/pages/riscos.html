⚠️ Matriz de Riscos

Riscos Técnicos

Risco Severidade Probabilidade Mitigação
Vazamento de dados entre tenants 🔴 Crítico Baixa Validação de ownership em cada request
Escalation de privilégios via JWT fake 🔴 Crítico Média Verificação rigorosa de JWT secret + expires
Chrome/Xvfb crash → sessão não termina 🟡 Médio Média Watchdog de processos + timeout auto-kill
Memory leak em sessões longas 🟡 Médio Alta Auto-destroy após timeout; limitar sessões simultâneas
DoS por many-sessions 🔴 Crítico Alta Limite por tenant + monitoramento
Vírus/Malware baixado pelo Xvfb 🟡 Médio Baixa Não executar binários; jail container
Perfil roubado (cookies sensíveis) 🔴 Crítico Média Criptografar profile at rest
Sincronização vídeo/áudio dessincronizada 🟢 Baixo Alta Timestamping; NTP synchronization

Riscos Operacionais

  • Alta carga de CPU: Multiplas sessões 1080p — precisa monitoração
  • 🔄 Fluxo Completo
  • Espaço em disco: Perfiles crescem sem limpeza — precisa rotacionar
  • Ataques XSS via browser: Site acessado pode tentar roubar token — usar sandboxed iframe no frontend
  • Latência: Rede instável resulta em choppy streaming
  • 🔄 Fluxo Completo

Checklist de Mitigação

[ ] All requests validated: tenantId, ownership
[ ] JWT secret é forte (64+ chars) e em vault
[ ] HTTPS/TLS configurado com cipher forte
[ ] Rate limiter por tenant
[ ] Login WAF/Log monitor
[ ] Backup automático do DB
[ ] Watchdog de processos Xvfb/Chrome
[ ] Log de auditoria (quem acessou o quê)
[ ] CORS configurado corretamente
[ ] Content-Security-Policy headers
[ ] SQLite VACUUM semanal
[ ] Profiles criptografados (opcional)
[ ] Limite de sessões por tenant (configurável)
[ ] Monitoramento de memória/cpu por sessão
[ ] Alertas para crash de sessões
[ ] Secret rotation policy (JWT_SECRET)
