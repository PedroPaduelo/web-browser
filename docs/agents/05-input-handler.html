Input Handler Agent

Agente de simulação de entrada para X11 via python-xlib

Ativo

Arquitetura

O Input Handler Agent é responsável por receber comandos de input do cliente e convertê-los em eventos X11 reais no display virtual. A comunicação ocorre através de um processo Python que escuta stdin e usa a extensão XTest para simular eventos.

API do Input Handler

createInputHandler(displayNum)

Cria e spawna um processo Python que manipula o display X11 especificado. O processo Python (x11-input.py) é iniciado com a variável de ambiente SERENDE_DISPLAY=:displayNum apontando para o display virtual.

const { createInputHandler } = require('./input-handler'); // Criar handler para display virtual :100 const input = createInputHandler('100');

Retorno

Objeto com os seguintes métodos:

Método Descrição
sendInput(msg) Envia uma mensagem JSON para o stdin do processo Python. O JSON deve conter o tipo de input e seus parâmetros.
stop() Encerra o processo Python, fechando o stdin e matando o processo.

Tipos de Input

JSON aceitos pelo sendInput()
Tipo Parâmetros Descrição
mousemove x, y Move o cursor do mouse para as coordenadas especificadas.
mousedown x, y, button (opcional) Pressiona o botão do mouse. Button: 0 = esquerdo, 1 = meio, 2 = direito.
mouseup x, y, button (opcional) Libera o botão do mouse.
keydown key, keyCode (opcional) Pressiona uma tecla do teclado.
keyup key, keyCode (opcional) Libera uma tecla do teclado.
wheel deltaX, deltaY Simula rolagem da roda do mouse. Valores positivos sobem, negativos descem.
scroll deltaX, deltaY Idêntico ao wheel,move o cursor para (x,y) antes de rolar.

Exemplos de Uso

// Mover mouse input.sendInput({ type: 'mousemove', x: 800, y: 600 }); // Clique esquerdo input.sendInput({ type: 'mousedown', x: 800, y: 600, button: 0 }); input.sendInput({ type: 'mouseup', x: 800, y: 600, button: 0 }); // Pressionar tecla 'A' input.sendInput({ type: 'keydown', key: 'a' }); input.sendInput({ type: 'keyup', key: 'a' }); // Rolagem input.sendInput({ type: 'wheel', deltaX: 0, deltaY: -120 }); input.sendInput({ type: 'scroll', deltaX: 0, deltaY: 100 });

Mapeamento de Teclas

Como o keyCode é interpretado pelo Python

O Python (x11-input.py) utiliza a biblioteca python-xlib para converter strings de teclas em keycodes X11. Existe um mapeamento interno para teclas especiais e qualquer caractere simples pode ser usado diretamente.

Como Funciona

  1. Se a chave key existe no KEY_MAP, usa o valor mapeado
  2. Usa XK.string_to_keysym() para converter para keysym X11
  3. Usa d.keysym_to_keycode() para obter o keycode numérico
  4. O keycode é enviado via XTest.fake_input()

Processo Python (x11-input.py)

Detalhes da implementação

Visão Geral

O script x11-input.py é um processo Python de longa duração que:

  1. Conecta ao display X11 especificado via variável SERENDE_DISPLAY
  2. Lê linhas JSON do stdin em loop infinito
  3. Interpreta cada mensagem e executa o evento X11 correspondente
  4. Usa a extensão XTest para simular eventos reais

Dependências

# Instalação das dependências Python pip install python-xlib

Variáveis de Ambiente

Variável Descrição Default
SERENDE_DISPLAY Display X11 virtual (ex: :100) :100

Fluxo de Execução

1. Inicialização init_display() Conecta ao display X11 usando python-xlib
2. Loop Principal while True Lê linhas JSON do stdin em loop infinito
3. Processamento handle_msg() Interpreta o JSON e executa XTest.fake_input()
4. Flush d.flush() Envia os eventos pendentes para o servidor X11

Integração com Chrome/Xvfb

O Input Handler opera em conjunto com o Xvfb (X Virtual Framebuffer) e o Chrome. O Xvfb cria um display virtual onde o Chrome pode executar sem monitor físico, e o Input Handler injeta eventos nesse display.
