Rate Limiting

Duas camadas de proteção
1
Rate Limiter Global
app.use(rateLimit(...))
Aplica a todos os endpoints da API. Configurável via variáveis de ambiente. Protege contra ataques de negação de serviço distribuído.
100
req/window (padrão)
60s
janela (padrão)
2
Login Rate Limiter
/auth/login
Proteção específica para endpoint de autenticação. Previne força bruta com limitação rigorosa e limpeza automática de registros.
5
tentativas/IP
60s
janela fixa
Cleanup a cada 5min

Headers de Segurança

Configuração do Helmet.js
O Helmet é configurado com proteções padrão, mas com CSP e COEP desabilitados para garantir compatibilidade com funcionalidades que utilizam iframes ou cross-origin.
Header Valor Status Descrição
Strict-Transport-Security max-age=31536000 Ativo Força HTTPS por 1 ano
X-Frame-Options DENY Ativo Previne clickjacking
X-Content-Type-Options nosniff Ativo Evita MIME-sniffing
Referrer-Policy strict-origin-when-cross-origin Ativo Controla informação de referrer
Permissions-Policy geolocation=(), camera=() Ativo Desativa APIs sensíveis
Content-Security-Policy Desabilitado Desativado Compatibilidade com iframes COOP/COEP
Cross-Origin-Embedder-Policy Desabilitado Desativado Necessário para SharedArrayBuffer

CORS

Cross-Origin Resource Sharing configurável
Configuração flexível via variável de ambiente CORS_ORIGIN. Suporta múltiplas origens separadas por vírgula.
Configuração Valor Padrão Variável de Ambiente
Origin * (qualquer origem) CORS_ORIGIN
Methods GET, POST, DELETE, PATCH, OPTIONS —
Allowed Headers Content-Type, Authorization, x-admin-secret, x-api-key —
Credentials false —
Max Age 86400 (24h) —
cors: ( process.env.CORS_ORIGIN?.split(',').map((o) => o.trim()) || ['*'] )

Logging Estruturado

JSON logs com contexto
O sistema sobrescreve console.log, console.error e console.warn para gerar logs estruturados em formato JSON automaticamente.
{ "timestamp": "2025-03-14T02:21:00.123Z", "level": "info", "requestId": "a1b2c3d4", "method": "POST", "path": "/api/auth/login", "statusCode": 200, "responseTime": 145, "message": "Login successful", "userId": "user_12345" }
{ "timestamp": "2025-03-14T02:21:05.456Z", "level": "error", "requestId": "e5f6g7h8", "method": "POST", "path": "/api/auth/login", "statusCode": 401, "message": "Invalid credentials", "ip": "192.168.1.100" }
timestamp — Data/hora UTC
level — info | warn | error
requestId — Rastreabilidade
responseTime — Tempo em ms

Error Handler

Tratamento centralizado de erros
O error handler captura todas as exceções não tratadas e retorna resposta JSON consistente com requestId para rastreamento. Stack trace completo em desenvolvimento.
{ "error": "Internal Server Error", "requestId": "a1b2c3d4", "message": "Database connection failed", "stack": "Error: Database connection failed\n at Pool.connect..." }
{ "error": "Validation Error", "requestId": "e5f6g7h8", "message": "Invalid email format" }

Implementação

Referência no código fonte
// index.js — Security Middleware Pipeline // 1. Trust Proxy (EasyPanel) app.set('trust proxy', parseInt(process.env.TRUST_PROXY) || 1); // 2. Helmet Security Headers app.use( helmet({ contentSecurityPolicy: false, crossOriginEmbedderPolicy: false }) ); // 3. CORS app.use( cors({ origin: process.env.CORS_ORIGIN?.split(',').map((o) => o.trim()) || ['*'], methods: ['GET', 'POST', 'DELETE', 'PATCH', 'OPTIONS'], allowedHeaders: ['Content-Type', 'Authorization', 'x-admin-secret', 'x-api-key'], credentials: false, maxAge: 86400 }) ); // 4. Body Parser app.use(express.json({ limit: '1mb' })); // 5. Global Rate Limiter const globalLimiter = rateLimit({ windowMs: parseInt(process.env.RATE_LIMIT_WINDOW_MS) || 60000, max: parseInt(process.env.RATE_LIMIT_MAX_REQUESTS) || 100, standardHeaders: true, legacyHeaders: false }); app.use(globalLimiter); // 6. Request ID Generator app.use((req, res, next) => { req.id = crypto.randomUUID().slice(0, 8); res.setHeader('X-Request-Id', req.id); next(); }); // 7. Auth Rate Limiter (specific to /auth routes) const authLimiter = rateLimit({ windowMs: 60 * 1000, max: 5, message: { error: 'Muitas tentativas de login', retryAfter: 60 } }); // 8. Structured Logging console.log = (...args) => logger('info', ...args); console.error = (...args) => logger('error', ...args); console.warn = (...args) => logger('warn', ...args); // 9. Error Handler (after all routes) app.use(errorHandler); // 10. 404 Handler (catch-all) app.use((req, res) => { res.status(404).json({ error: 'Not found', requestId: req.id }); });
