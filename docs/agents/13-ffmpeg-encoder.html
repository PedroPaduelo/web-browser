FFmpeg Encoder Agent

Media

Agente de codificação de tela X11 para MJPEG em baixa latência, implementado em session-manager.js.

Argumentos

Argumentos FFmpeg otimizados para menor latência possível e saída MJPEG por pipe.

ArgumentoDescrição
-probesize 32Reduz o tempo de detecção de formato de entrada, permitindo iniciar mais rápido.
-analyzeduration 0Desativa análise prévia. Usa apenas os primeiros dados para iniciar a captura.
-fflags nobuffer+flush_packetsDesabilita buffering e força os pacotes a serem liberados rapidamente.
-flags low_delayHabilita modo de baixa latência no codificador.
-f x11grabUsa captura de tela X11 (Xvfb ou display real).
-framerate 30Captura a 30 FPS alvo.
-video_size 1280x720Resolução de captura (exemplo). Ajustar conforme disponibilidade do display.
-draw_mouse 0Não desenha cursor no frame; o cursor é virtualmente gerenciado.
-thread_queue_size 16Fila de leitura de threads pequena para reduzir buffering interno.
-i :100Display X11 de origem. Ex: :100.
-f mjpegSaída de vídeo no formato MJPEG, frame independente para streaming rápido.
-q:v 5Qualidade JPEG (1 melhor, 31 pior). 5 costuma equilibrar qualidade e compressão.
-huffman optimalUsa codificação Huffman otimizada para tamanhos de imagem menores.
-anRemove áudio (sem trilha de áudio no stream).
-flush_packets 1Força flush imediato dos pacotes para reduzir latência de entrega.
pipe:1Escreve saída por stdout para consumo pelo StreamManager.

Pipeline de Vídeo

Xvfb display → FFmpeg x11grab → MJPEG frames → stdout (pipe:1) → StreamManager → WebSocket

O agente lê do display X11 gerenciado (geralmente Xvfb), codifica a tela como MJPEG em tempo real e passa pelo pipe para o StreamManager, que transmite via WebSocket para clientes.

Qualidade vs Performance

O parâmetro -q:v 5 controla a qualidade JPEG por frame:

  • 1 = melhor qualidade, maior tamanho de quadro e maior CPU.
  • 31 = menor qualidade, menor taxa de bits e menor carga computacional.

Valor 5 é um bom compromisso para baixa latência e qualidade visual aceitável em transmissões de tela.

Latência

O FFmpeg Encoder Agent é ajustado para reduzir latência em cada etapa:

  • -probesize 32 e -analyzeduration 0 reduzem atrasos de inicialização.
  • -fflags nobuffer+flush_packets e -flush_packets 1 evitam acumulação de pacotes no pipeline.
  • -flags low_delay diminui a criação de buffers internos no codificador.
  • pipe:1 entrega imediata ao StreamManager para envio rápido via WebSocket.

Com esses ajustes, os quadros chegam ao cliente o mais rápido possível, mantendo a estabilidade do stream.
