Tenant Manager Agent

Gerenciamento de isolamento de perfis Chrome por tenant no filesystem.

Ativo

Visão Geral

tenant-manager.js controla a criação, cópia, merge e limpeza de perfis de sessão isolados por tenant.

Constantes essenciais

  • DATA_DIR - diretório raiz dos dados do agent.
  • TENANTS_DIR - pasta de tenants: data/tenants.
  • ESSENTIAL_FILES - lista de arquivos que são sincronizados entre master e sessão:
  • Default/Cookies
  • Default/Preferences
  • Default/Bookmarks
  • Default/Login Data
  • Default/Web Data
  • Local State

Isolamento Multi-Tenant

Cada tenant tem um conjunto de perfis mestres, sessões e downloads separados.

data/tenants/<tenantId>/ ├── profile-master/Default/ │ ├── Cookies │ ├── Preferences │ ├── Bookmarks │ ├── "Login Data" │ ├── "Web Data" │ └── Local State ├── sessions/<sessionId>/profile/Default/ │ ├── Cookies │ ├── Preferences │ ├── Bookmarks │ ├── "Login Data" │ ├── "Web Data" │ └── Local State └── downloads/

Ciclo Copy/Merge

O fluxo de sincronização de perfil no Tenant Manager garante dados de sessão atualizados e consistentes.
Master (profile-master/Default) ↓ copyProfileToSession(tenantId, sessionId) Session (sessions/sessionId/profile/Default) ↓ (navegação/sessão ativa) ↓ mergeProfileFromSession(tenantId, sessionId) Master (profile-master/Default)

Arquivos Essenciais

Esses arquivos são necessários para manter estado de login, navegação e preferências do Chrome entre sessões.

Arquivo O que contém
Default/CookiesCookies de sessão, autenticação e rastreamento
Default/PreferencesConfigurações de usuário, UI e políticas do Chrome
Default/BookmarksMarcadores e organização de favoritos
Default/Login DataCredenciais e dados de login salvos
Default/Web DataFormulários, senhas e histórico de preenchimento
Local StateConfigurações globais do navegador e chaves de sessão

Funções

FunçãoComportamento

getSessionProfileDir(tenantId, sessionId)Retorna caminho do profile de sessão
copyProfileToSession(tenantId, sessionId)Copiar arquivos essenciais do master para sessão
mergeProfileFromSession(tenantId, sessionId)Mesclar arquivos essenciais da sessão de volta para o master
