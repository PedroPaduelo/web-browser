Profile Manager Agent

Ativo

Singleton responsável pelo gerenciamento de metadados dos perfis de tenant no sistema Serende.

Visão Geral

O Profile Manager Agent é uma classe singleton (profile-manager.js) que gerencia os metadados dos perfis de tenant. Suas principais responsabilidades incluem:

  • Verificar existência do diretório masterDir de cada tenant
  • Ler e salvar arquivos metadata.json com informações do perfil
  • Gerenciar a limpeza completa de perfis de tenant
  • Retornar diretórios de dados de sessão para o _default
  • Acompanhar atividade das sessões através de timestamps

Métodos

Método Assinatura Descrição
hasProfile async hasProfile(tenantId) Verifica se o diretório masterDir existe para o tenant.
loadMetadata async loadMetadata(tenantId) Lê o arquivo metadata.json do tenant. Retorna objeto com tenantId, savedAt, version, lastDisplay, lastActivity.
saveMetadata async saveMetadata(tenantId, extra) Salva/atualiza o metadata.json. Recebe objeto extra com campos a mesclar (ex: { lastActivity: Date.now() }).
cleanProfile async cleanProfile(tenantId) Remove recursivamente o masterDir do tenant. Usado para limpeza total do perfil.
getUserDataDir getUserDataDir(tenantId) Retorna o caminho completo do sessionProfileDir. Para _default, retorna diretamente o perfil default.
saveSessionState async saveSessionState(tenantId, displayNum) Salva metadata atualizando lastDisplay e lastActivity. Usado quando uma sessão é iniciada ou tem atividade.

Metadata JSON

O arquivo metadata.json armazena informações sobre o perfil do tenant:

{ "tenantId": "abc123def456...", "savedAt": 1742012400000, "version": "2.0", "lastDisplay": 100, "lastActivity": 1742012399123 }

Campos:
• tenantId: Identificador único do tenant
• savedAt: Timestamp (ms) da última modificação do arquivo
• version: Versão do formato do metadata (atualmente "2.0")
• lastDisplay: Número do último display X11 usado por este tenant
• lastActivity: Timestamp (ms) da última atividade detectada

Integração com Tenant Manager

O Profile Manager Agent trabalha em conjunto com o Tenant Manager para gerenciar o ciclo de vida completo dos perfis:

┌─────────────────┐ │ Tenant Mgr │ │ (api/web) │ └────────┬────────┘ │ requer perfil ▼ ┌─────────────────────────────────────────┐ │ Profile Manager │ │ (singleton) │ ├─────────────────────────────────────────┤ │ • hasProfile(tenantId) │ │ • loadMetadata(tenantId) ──────────────►│ │ • saveMetadata(tenantId, extra) │ │ • cleanProfile(tenantId) │ │ • getUserDataDir(tenantId) ────────────►│ │ • saveSessionState(tenantId, display) │ └─────────────────────────────────────────┘ │ ▼ ┌─────────────────┐ │ File System │ │ data/tenants/ │ │ ├─ metadata.js │ │ └─ profile-... │ └─────────────────┘

O Tenant Manager é o principal consumidor dos métodos do Profile Manager. Quando uma sessão é criada, o Tenant Manager usa getUserDataDir para obter o perfil e saveSessionState para registrar a atividade. Ao limpar perfis órfãos, usa cleanProfile e hasProfile para verificar existência.
