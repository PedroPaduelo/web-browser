Stream Manager Agent

agents/stream-manager.js

Responsável pelo streaming de vídeo MJPEG via WebSocket. Recebe frames codificados do FFmpeg, detecta boundaries JPEG (SOI/EOI), bufferiza e transmite para todos os clientes conectados com controle de backpressure para evitar sobrecarga.

Protocolo MJPEG

Detecção de frames JPEG

Marcadores JPEG (SOI/EOI)

O sistema detecta frames completos procurando por marcadores JPEG no buffer binário. Cada frame começa com SOI (Start of Image) e termina com EOI (End of Image).

// Constantes JPEG markers const SOI = 0xFFD8; // Start of Image (0xFF 0xD8) const EOI = 0xFFD9; // End of Image (0xFF 0xD9) // Extração via matching de bytes extractFrames() { for (let i = 0; i < this.buffer.length - 1; i++) { if (this.buffer[i] === 0xFF && this.buffer[i+1] === 0xD8) { this.frameStart = i; } if (this.buffer[i] === 0xFF && this.buffer[i+1] === 0xD9) { const frameEnd = i + 2; const frame = this.buffer.slice(this.frameStart, frameEnd); this.buffer = this.buffer.slice(frameEnd); this.broadcastFrame(frame); } } }

Backpressure

Controle de fluxo e throttling

Mecanismo de Controle

O sistema monitora o buffer de cada cliente WebSocket. Quando o buffer ultrapassa 128KB, o streaming é temporariamente suspenso até que o cliente recupere.

broadcastFrame(frame) { const bufferSize = 128 * 1024; // 128KB throttle threshold this.clients.forEach(ws => { if (ws.bufferSize > bufferSize) { // Cliente lento: remove frame e loga aviso console.debug('Backpressure: cliente buffer cheio'); return; } if (ws.readyState === WebSocket.OPEN) { ws.send(frame); } }); }

O que é Backpressure?

Backpressure é um mecanismo de controle de fluxo que impede que um produtor mais rápido (FFmpeg) sobrecarregue um consumidor mais lento (cliente WebSocket). Ao detectar que o buffer do cliente está cheio, o sistema pausa temporariamente o envio de frames até que haja espaço disponível.

Notas Técnicas

Considerações de implementação

Buffer Dinâmico

O buffer de 512KB inicial é apenas um ponto de partida. O método extractFrames() atualiza continuamente o buffer, consumindo frames processados e preservando bytes pendentes. O buffer cresce automaticamente se houver latência no processamento.

Formato MJPEG

MJPEG (Motion JPEG) é uma sequência de imagens JPEG independentes. Cada frame é uma imagem JPEG completa, permitindo que o cliente renderize frame por frame sem dependências. Isso é ideal para streaming de baixa latência via WebSocket.

WebSocket Backpressure

Cada WebSocket no Node.js tem um buffer interno. A resposta verifica ws.bufferSize para evitar acumulação. Clientes lentos podem perder frames, mas não causam vazamento de memória. Isso é comportamento aceitável para streaming em tempo real.

Cleanup

O método stop() deve ser chamado ao encerrar sessões para evitar memory leaks. Ele limpa o buffer, remove todos os clients do Set e fecha todas as conexões WebSocket abertas.
