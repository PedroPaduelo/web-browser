Audio Manager Agent

Desativado

Módulo opcional para captura e streaming de áudio da sessão remota via PulseAudio/ALSA.

Status Atual

DESATIVADO — Funcionalidade de áudio não está disponível

O sistema atualmente funciona apenas com streaming de vídeo MJPEG através do WebSocket. O áudio pode ser habilitado futuramente se necessário.

Funcionalidades Planejadas

  • ✓ Captura de áudio do PulseAudio ou ALSA
  • ✓ Streaming via WebRTC ou WebSocket
  • ✓ Sincronização com stream de vídeo
  • ✓ Controle de volume (mute/unmute)

Componentes Frontend

Os seguintes componentes TypeScript foram preparados no frontend mas estão atualmente inativos:

📄 AudioManager.tsx — Gerencia estado do áudio e controle de microfone
📄 AudioControl.tsx — Controles de volume e mute/unmute

Como Ativar

Para habilitar o áudio no sistema, seria necessário:

  1. Garantir que pulseaudio ou alsa-utils estejam instalados no sistema
  2. Carregar e iniciar o módulo audio-manager.js no servidor
  3. Configurar sink virtual do PulseAudio para captura de áudio
  4. Integrar broadcasts de áudio via WebSocket ao frontend
  5. Implementar recepção e reprodução WebAudio no lado do cliente

Dependências

As seguintes dependências do sistema não são instaladas por padrão:

pulseaudio alsa-utils Módulo de áudio para Node.js ffmpeg (com suporte a pulse)

Arquivo de Implementação

O código-fonte do agente está localizado em:

⚙️ ./server/audio-manager.js

O módulo implementa inicialização do PulseAudio, captura via ffmpeg e broadcast PCM via WebSocket.
