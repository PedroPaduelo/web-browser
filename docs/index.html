Serende

Sistema de navegação remota via browser — VNC over Web.
Chrome headless + Xvfb + FFmpeg + WebSocket = acesso remoto a um navegador real via qualquer browser moderno.

📚 Documentação Completa

🏗️ Arquitetura

Diagrama de componentes, tecnologias, portas, fluxo de dados principal.

🔐 Autenticação

API Keys (SHA256), JWT (HS256, 24h), rate limiting (5/min login), admin routes.

💻 Sessões

Ciclo de vida completo: alocação de display, spawn de processos, timeout, encerramento.

🎬 Streaming de Vídeo

Pipeline FFmpeg → MJPEG → WebSocket binário → Canvas. 30 FPS, backpressure.

🖱️ Input Relay

DOM events → JSON → WebSocket → Python x11-input.py → XTest → Xvfb.

👤 Profiles

Chrome profile persistente por tenant. Master → sessão → merge. Cookies, logins, bookmarks.

🔊 Áudio

PulseAudio virtual → PCM s16le → WebSocket → Web Audio API.

🏢 Multi-tenant

Isolamento por API key. TenantId = SHA256. Limites independentes por tenant.

🌐 API REST

24 endpoints: auth, session CRUD, input, CDP control, profile, admin.

⚡ WebSocket

2 canais: /ws/stream (JPEG binário) e /ws/input (JSON). Reconexão automática.

🛡️ Segurança

6 camadas: Helmet, Rate Limit, JWT, API Keys, CORS, Trust Proxy.

⚛️ Frontend

React 18 + TypeScript + Vite. Canvas rendering, WsClient, auth hooks.

💾 Banco de Dados

SQLite WAL mode. Tabela api_keys. Key store CRUD. Dados em memória.

⚠️ Riscos

Matriz completa: 2 críticos, 3 altos, 3 médios, 2 baixos. Mitigações implementadas.

🔄 Fluxo Completo

End-to-end: login → sessão → streaming → uso → encerramento. Todos os endpoints.
