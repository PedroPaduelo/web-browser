Visão Geral do Sistema

O Remote Browser (Serende) é uma plataforma de navegação remota via API.

Backend Node.js

Servidor Express com WebSocket, gerenciamento de sessões Chrome e API REST.

Ver detalhes →

Frontend React

Interface React + Vite com canvas para renderização MJPEG e controles de sessão.

Ver detalhes →

Chrome Headless

Navegador Chrome rodando em Xvfb (display virtual) com CDP para controle remoto.

Ver detalhes →

Stream de Vídeo

Captura via CDP Screencast (JPEG) + WebSocket broadcast para múltiplos clientes.

Ver detalhes →

Input Relay

Sistema de input via X11 (XTest) que envia eventos de mouse/teclado para o Chrome.

Ver detalhes →

Autenticação

API Key → JWT com tenant isolation. Cada tenant tem limite de sessões.

Ver detalhes →

Profile Manager

Persistência de cookies, localStorage entre sessões. Backup/restore de profiles.

Ver detalhes →

API REST

Endpoints para sessões, navegação, profile, healthcheck. Rate limiting e CORS.

Ver detalhes →

MCP Server

Model Context Protocol para integração com Claude Desktop e IDEs.

Ver detalhes →

Riscos e Pontos Críticos

Limite de displays, memory leaks, cleanup de processos, race conditions.

Ver detalhes →
